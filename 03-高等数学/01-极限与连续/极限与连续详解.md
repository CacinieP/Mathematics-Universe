# 极限与连续详解

## 一、数列极限深化

### 1.1 收敛数列的性质

1. **唯一性**：收敛数列的极限唯一
2. **有界性**：收敛数列必有界
3. **保号性**：$\lim a_n = a > 0$ ⟹ $\exists N$，$n > N$ 时 $a_n > 0$
4. **保不等式**：$a_n \leq b_n$ ⟹ $\lim a_n \leq \lim b_n$
5. **夹逼性**：$a_n \leq c_n \leq b_n$，$\lim a_n = \lim b_n = L$ ⟹ $\lim c_n = L$

### 1.2 Cauchy收敛准则

**定理**：$\{a_n\}$ 收敛 ⟺ $\forall\varepsilon>0$，$\exists N$，$m,n>N$ 时 $|a_m-a_n|<\varepsilon$

**意义**：不需要知道极限值，仅通过序列内部性质即可判断收敛。

> **与完备性的联系**：Cauchy准则在 $\mathbb{R}$ 中成立，是因为 $\mathbb{R}$ 是完备的。在有理数集 $\mathbb{Q}$ 中，Cauchy序列不一定收敛（如 $\sqrt{2}$ 的有理逼近）。

### 1.3 Stolz定理（数列版L'Hôpital）

**$\frac{\infty}{\infty}$型**：若 $\{b_n\}$ 严格单调趋于 $+\infty$，且 $\lim\frac{a_{n+1}-a_n}{b_{n+1}-b_n} = L$，则 $\lim\frac{a_n}{b_n} = L$

**案例**：取固定非负整数 $k$，求 $\lim_{n\to\infty}\frac{1^k+2^k+\cdots+n^k}{n^{k+1}}$

令 $a_n = \sum_{i=1}^n i^k$，$b_n = n^{k+1}$

$\frac{a_{n+1}-a_n}{b_{n+1}-b_n} = \frac{(n+1)^k}{(n+1)^{k+1}-n^{k+1}} \sim \frac{n^k}{(k+1)n^k} = \frac{1}{k+1}$

所以极限 = $\frac{1}{k+1}$

> **与积分的联系**：$\lim\frac{\sum_{i=1}^n i^k}{n^{k+1}} = \frac{1}{k+1} = \int_0^1 x^k dx$（Riemann和！）

### 1.4 单调有界原理的典型应用

**案例1**：设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2+x_n}$，求 $\lim x_n$

**单调性**：$x_1 = \sqrt{2} \approx 1.414$，$x_2 = \sqrt{2+\sqrt{2}} \approx 1.848 > x_1$

归纳：假设 $x_n > x_{n-1}$，$x_{n+1} = \sqrt{2+x_n} > \sqrt{2+x_{n-1}} = x_n$ ✓

**有界性**：假设 $x_n < 2$，$x_{n+1} = \sqrt{2+x_n} < \sqrt{4} = 2$ ✓

所以 $\lim x_n = L$ 存在，$L = \sqrt{2+L}$，$L^2 = 2+L$，$L = 2$（舍去负根）

**案例2**：$x_n = \frac{1}{2}+\frac{1}{2\cdot 4}+\cdots+\frac{1}{2\cdot 4\cdots(2n)}$

$x_{n+1} = x_n + \frac{1}{2\cdot 4\cdots(2n)(2n+2)} = x_n + \frac{1}{2^n n! \cdot 2(n+1)} > x_n$

$x_n \leq \sum_{k=1}^n \frac{1}{2^k} = 1 - \frac{1}{2^n} < 1$（上界为1）

所以收敛。实际上 $x_n \to \sum_{k=1}^{\infty}\frac{1}{2^k k!}$

## 二、函数极限深化

### 2.1 七种未定式

| 类型 | 形式 | 解法 |
|------|------|------|
| $\frac{0}{0}$ | $\frac{f(x)}{g(x)}$，$f\to 0$，$g\to 0$ | 等价无穷小/L'Hôpital/Taylor |
| $\frac{\infty}{\infty}$ | $f\to\infty$，$g\to\infty$ | L'Hôpital/抓大头 |
| $0 \cdot \infty$ | $f\to 0$，$g\to\infty$ | 化为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ |
| $\infty - \infty$ | $f\to\infty$，$g\to\infty$ | 通分/有理化/提出公因子 |
| $1^\infty$ | $f\to 1$，$g\to\infty$ | 取对数→$0\cdot\infty$ |
| $0^0$ | $f\to 0^+$，$g\to 0^+$ | 取对数 |
| $\infty^0$ | $f\to\infty$，$g\to 0^+$ | 取对数 |

### 2.2 $1^\infty$型极限的速算公式

$\lim f(x)^{g(x)}$（$1^\infty$型）= $e^{\lim(f(x)-1)\cdot g(x)}$

**案例**：$\lim_{x\to 0}\left(\frac{\sin x}{x}\right)^{1/x^2}$

$\frac{\sin x}{x} \to 1$，$\frac{1}{x^2}\to\infty$，属于 $1^\infty$ 型

$\left(\frac{\sin x}{x}-1\right)\cdot\frac{1}{x^2} = \frac{\sin x - x}{x^3}$

Taylor展开：$\sin x = x - \frac{x^3}{6}+O(x^5)$

$\frac{-x^3/6}{x^3} = -\frac{1}{6}$

所以极限 = $e^{-1/6}$

### 2.3 L'Hôpital法则的使用条件

**条件**：
1. $\lim\frac{f(x)}{g(x)}$ 是 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型
2. 在去心邻域内 $f'(x)$ 和 $g'(x)$ 存在且 $g'(x)\neq 0$
3. $\lim\frac{f'(x)}{g'(x)}$ 存在（或为 $\infty$）

**常见错误**：
- 不是未定式就用L'Hôpital（如 $\lim_{x\to 1}\frac{x+1}{x^2+1}$，直接代入得1）
- 多次使用不检验条件
- 可以用等价无穷小简化的地方硬用L'Hôpital

### 2.4 案例：$\lim_{x\to +\infty}\frac{x^2}{e^x}$

$\frac{\infty}{\infty}$ 型，用L'Hôpital：

$\lim\frac{x^2}{e^x} = \lim\frac{2x}{e^x} = \lim\frac{2}{e^x} = 0$

**启示**：指数函数增长比任何多项式都快。$\forall n$，$\lim_{x\to\infty}\frac{x^n}{e^x} = 0$。

**增长速度排序**：$\ln x \ll x^n \ll a^x \ll x! \ll x^x$（固定 $n>0$、$a>1$，$x$ 沿正整数趋于无穷）

## 三、连续性深化

### 3.1 一致连续

**定义**：$\forall\varepsilon>0$，$\exists\delta>0$，$\forall x_1,x_2$，$|x_1-x_2|<\delta \Rightarrow |f(x_1)-f(x_2)|<\varepsilon$

**与逐点连续的区别**：$\delta$ 只依赖 $\varepsilon$，不依赖 $x$。

**Cantor定理**：闭区间上连续 ⟹ 一致连续

**反例**：$f(x) = \frac{1}{x}$ 在 $(0,1)$ 上不一致连续。

证明：固定 $\varepsilon=1$。对任意 $\delta>0$，令 $h=\min(\delta/2,1/2)$，取 $x_1=h$、$x_2=h/2$。两点都在 $(0,1)$，且
$$|x_1-x_2|=h/2<\delta,\qquad |f(x_1)-f(x_2)|=1/h\geq2>1.$$
因此没有一个 $\delta$ 能统一满足要求，故不一致连续。

### 3.2 闭区间连续函数定理的证明思路

**零点定理**：$f$ 在 $[a,b]$ 连续，且 $f(a) < 0 < f(b)$ ⟹ $\exists c \in (a,b)$，$f(c) = 0$

**证明**（二分法思想）：
1. 取中点 $c_0 = \frac{a+b}{2}$
2. 若 $f(c_0) = 0$，完成
3. 若 $f(c_0) > 0$，在 $[a,c_0]$ 中继续
4. 若 $f(c_0) < 0$，在 $[c_0,b]$ 中继续
5. 得到区间套 $\{[a_n,b_n]\}$，长度 $\to 0$
6. 由区间套定理，$\exists$ 唯一 $c \in \bigcap [a_n,b_n]$
7. 由连续性和保号性，$f(c) = 0$

> **与数值分析的联系**：这个证明过程本身就是**二分法求根**的算法。
