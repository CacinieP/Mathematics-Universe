# 多元微分学详解

## 一、多元函数的极限与连续

### 1.1 二重极限

**定义**：$\lim_{(x,y)\to(x_0,y_0)}f(x,y) = L$

$\forall\varepsilon>0$，$\exists\delta>0$，$0<\sqrt{(x-x_0)^2+(y-y_0)^2}<\delta \Rightarrow |f(x,y)-L|<\varepsilon$

**关键**：$(x,y)$ 以**任意路径**趋于 $(x_0,y_0)$，极限都相同。

**证明极限不存在**：找两条路径使极限值不同。

**案例**：$\lim_{(x,y)\to(0,0)}\frac{xy}{x^2+y^2}$

沿 $y = kx$：$\frac{kx^2}{x^2+k^2x^2} = \frac{k}{1+k^2}$（依赖 $k$）

不同路径极限不同，所以极限不存在。

### 1.2 累次极限

$\lim_{x\to x_0}\lim_{y\to y_0}f(x,y)$ vs $\lim_{y\to y_0}\lim_{x\to x_0}f(x,y)$

这两个极限**不一定相等**！

**案例**：$f(x,y) = \frac{x-y}{x+y}$（$x+y\neq 0$）

$\lim_{x\to 0}\lim_{y\to 0}f = \lim_{x\to 0}\frac{x}{x} = 1$

$\lim_{y\to 0}\lim_{x\to 0}f = \lim_{y\to 0}\frac{-y}{y} = -1$

**定理**：若二重极限存在且两个累次极限都存在，则三者相等。

## 二、偏导数与全微分

### 2.1 高阶偏导数与求导顺序

**定理**（Clairaut）：若 $f_{xy}$ 和 $f_{yx}$ 在 $(x_0,y_0)$ 的邻域内连续，则 $f_{xy} = f_{yx}$。

**反例**（混合偏导不相等）：
$$f(x,y) = \begin{cases}\frac{xy(x^2-y^2)}{x^2+y^2}, & (x,y)\neq(0,0)\\0, & (x,y)=(0,0)\end{cases}$$

$f_{xy}(0,0) = -1$，$f_{yx}(0,0) = 1$（不相等！）

### 2.2 可微的充分条件

**定理**：偏导数连续 ⟹ 可微

**判断链**：
```
偏导数连续 → 可微 → 偏导数存在
                  ↘ 连续
```

不可逆！偏导数存在不一定连续，不一定可微。

### 2.3 复合函数求导（链式法则）

**情形一**：$z = f(u,v)$，$u = \varphi(x,y)$，$v = \psi(x,y)$

$$\frac{\partial z}{\partial x} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial x}+\frac{\partial f}{\partial v}\frac{\partial v}{\partial x}$$

$$\frac{\partial z}{\partial y} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial y}+\frac{\partial f}{\partial v}\frac{\partial v}{\partial y}$$

**情形二**：$z = f(x,y)$，$y = y(x)$

$$\frac{dz}{dx} = \frac{\partial f}{\partial x}+\frac{\partial f}{\partial y}\frac{dy}{dx}$$

**案例**：$z = e^{x^2+y^2}$，$y = \sin x$，求 $\frac{dz}{dx}$

$\frac{dz}{dx} = 2xe^{x^2+y^2}+2ye^{x^2+y^2}\cos x = 2e^{x^2+\sin^2 x}(x+\sin x\cos x)$

### 2.4 隐函数求导

**一个方程** $F(x,y) = 0$：
$$\frac{dy}{dx} = -\frac{F_x}{F_y}$$

**一个方程** $F(x,y,z) = 0$：
$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$

**方程组** $\begin{cases}F(x,y,u,v)=0\\G(x,y,u,v)=0\end{cases}$：

对 $x$ 求偏导：
$$\begin{cases}F_x+F_u u_x+F_v v_x = 0\\G_x+G_u u_x+G_v v_x = 0\end{cases}$$

解线性方程组：
$$u_x = -\frac{\begin{vmatrix}F_x&F_v\\G_x&G_v\end{vmatrix}}{\begin{vmatrix}F_u&F_v\\G_u&G_v\end{vmatrix}}$$

> **与线代的联系**：隐函数求导中的分母是Jacobi行列式 $\frac{\partial(F,G)}{\partial(u,v)}$。行列式非零 ⟺ 隐函数存在（隐函数存在定理）。

## 三、多元极值

### 3.1 无条件极值

**步骤**：
1. 求驻点：$\nabla f = 0$（解方程组）
2. 判别：计算Hessian矩阵 $H = \begin{pmatrix}f_{xx}&f_{xy}\\f_{yx}&f_{yy}\end{pmatrix}$

| 条件 | 结论 |
|------|------|
| $f_{xx} > 0$ 且 $\|H\| > 0$ | 极小值 |
| $f_{xx} < 0$ 且 $\|H\| > 0$ | 极大值 |
| $\|H\| < 0$ | 鞍点 |
| $\|H\| = 0$ | 无法判定 |

> **与线代的联系**：$H$ 正定 = 极小，$H$ 负定 = 极大，$H$ 不定 = 鞍点。这完全对应二次型的正定/负定/不定。

### 3.2 条件极值（Lagrange乘数法）

**问题**：在 $g(x,y) = 0$ 下求 $f(x,y)$ 的极值

$L(x,y,\lambda) = f(x,y) + \lambda g(x,y)$

解：$\frac{\partial L}{\partial x} = 0$，$\frac{\partial L}{\partial y} = 0$，$\frac{\partial L}{\partial\lambda} = 0$

**案例**：在 $x+y=1$（$x,y > 0$）条件下求 $xy$ 的最大值。

$L = xy + \lambda(1-x-y)$

$L_x = y - \lambda = 0$，$L_y = x - \lambda = 0$，$L_\lambda = 1-x-y = 0$

$y = \lambda$，$x = \lambda$，$2\lambda = 1$，$\lambda = 1/2$

$x = y = 1/2$，最大值 = $1/4$

> **与不等式的联系**：$\frac{x+y}{2} \geq \sqrt{xy}$（均值不等式），$x+y=1$ 时 $xy \leq 1/4$。Lagrange乘数法给出了均值不等式的几何证明。

### 3.3 多个约束的Lagrange乘数法

在 $g_1(x,y,z)=0$，$g_2(x,y,z)=0$ 下求 $f(x,y,z)$ 的极值：

$L = f + \lambda_1 g_1 + \lambda_2 g_2$

解5个未知量（$x,y,z,\lambda_1,\lambda_2$）的5个方程。

**几何意义**：极值点处，$\nabla f$ 在 $\nabla g_1$ 和 $\nabla g_2$ 张成的平面内。
