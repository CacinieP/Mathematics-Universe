# 无穷级数详解

## 一、正项级数

### 1.1 判别法比较

| 判别法 | 条件 | 适用 | 强度 |
|--------|------|------|------|
| 比较法 | $a_n \leq b_n$ | 与已知级数比较 | 基础 |
| 极限比较法 | $\lim a_n/b_n = c$ | 等价无穷小 | 常用 |
| 比值法 | $\lim a_{n+1}/a_n = \rho$ | 含阶乘/指数 | 强 |
| 根值法 | $\lim\sqrt[n]{a_n} = \rho$ | 含n次幂 | 更强 |
| 积分法 | $a_n = f(n)$ 递减 | 可积函数 | 特殊 |

**极限比较判别**：对正项级数，若 $\lim a_n/b_n=c$ 且 $0<c<+\infty$，则 $\sum a_n$ 与 $\sum b_n$ 同敛散。比值法、根值法中 $\rho<1$ 收敛、$\rho>1$ 发散，$\rho=1$ 时不能判定。积分判别要求 $f$ 在尾部非负、连续且单调不增。

### 1.2 常用比较级数

- $\sum\frac{1}{n^p}$：$p > 1$ 收敛，$p \leq 1$ 发散（$p$-级数）
- $\sum_{n=2}^{\infty}\frac{1}{n(\ln n)^p}$：$p > 1$ 收敛，$p\leq1$ 发散（Bertrand级数）
- $\sum r^n$：$|r| < 1$ 收敛（等比级数）

### 1.3 案例

**$\sum\frac{n!}{n^n}$**（比值法）

$\frac{a_{n+1}}{a_n} = \frac{(n+1)!/(n+1)^{n+1}}{n!/n^n} = \frac{n^n}{(n+1)^n} = \frac{1}{(1+1/n)^n} \to \frac{1}{e} < 1$

收敛。

**$\sum\frac{2^n+(-3)^n}{3^n}$**

$= \sum\left(\frac{2}{3}\right)^n + \sum(-1)^n$

第一个等比级数收敛（$2/3 < 1$），第二个通项不趋于0，发散。

所以原级数发散。

## 二、交错级数与条件收敛

### 2.1 Leibniz判别法

$\sum(-1)^{n-1}a_n$（$a_n > 0$），若 $a_n$ 单调递减趋于0，则收敛。

**案例**：$\sum\frac{(-1)^{n-1}}{\ln(n+1)}$

$a_n = \frac{1}{\ln(n+1)}$ 单调递减趋于0，由Leibniz判别法，收敛。

但 $\sum\frac{1}{\ln(n+1)} > \sum\frac{1}{n+1}$ 发散，所以条件收敛。

### 2.2 绝对收敛的性质

- 绝对收敛级数的和 = 交换顺序后的和（绝对收敛的重排不变性）
- 两个绝对收敛级数可以Cauchy乘积
- 绝对收敛 ⟹ 收敛（反之不成立）

## 三、幂级数

### 3.1 收敛半径

**公式**：$R = \frac{1}{\limsup_{n\to\infty}\sqrt[n]{|a_n|}}$

或（系数从某项起均非零，且极限存在或趋于正无穷时）：$R = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right|$。Cauchy–Hadamard 公式约定 $1/0=+\infty$、$1/(+\infty)=0$。

**收敛区间**：$|x-x_0| < R$ 内绝对收敛，$|x-x_0| > R$ 发散，端点单独讨论。

### 3.2 幂级数的分析性质

在收敛区间 $(x_0-R, x_0+R)$ 内：
1. **逐项可导**：$\left(\sum a_n(x-x_0)^n\right)' = \sum na_n(x-x_0)^{n-1}$，收敛半径不变
2. **逐项可积**：$\int\sum a_n(x-x_0)^n dx = \sum\frac{a_n}{n+1}(x-x_0)^{n+1}+C$，收敛半径不变
3. **内闭一致收敛**

### 3.3 函数展开为幂级数

**方法**：
1. 用 Taylor 公式计算系数，并证明余项趋于 0
2. 间接法：利用已知展开式+逐项求导/积分/变量代换

**不能省略还原条件**：无限次可导不保证函数等于其 Taylor 级数。例如 $f(0)=0$、$f(x)=e^{-1/x^2}$（$x\neq0$）在 0 的所有阶导数都是 0，Taylor 级数恒为 0，却不能在 0 的任何邻域还原 $f$。参见 [UC Davis：Hunter《Power Series》§10.7](https://www.math.ucdavis.edu/~hunter/intro_analysis_pdf/ch10.pdf)。

**案例**：将 $\frac{1}{1+x^2}$ 展开为 $x$ 的幂级数

$\frac{1}{1+t} = \sum_{n=0}^{\infty}(-1)^nt^n$（$|t|<1$）

令 $t = x^2$：$\frac{1}{1+x^2} = \sum_{n=0}^{\infty}(-1)^nx^{2n}$（$|x|<1$）

**逐项积分**：$\arctan x = \int_0^x\frac{dt}{1+t^2} = \sum_{n=0}^{\infty}\frac{(-1)^n}{2n+1}x^{2n+1}$（$|x|\leq 1$；注意端点 $x=\pm 1$ 的收敛需另证（交错级数判别/Abel定理），逐项积分只保证 $|x|<1$）

令 $x=1$：$\frac{\pi}{4} = 1-\frac{1}{3}+\frac{1}{5}-\frac{1}{7}+\cdots$（Leibniz公式）

### 3.4 级数求和

**案例**：求 $\sum_{n=1}^{\infty}\frac{n}{2^n}$

先由比值法 $a_{n+1}/a_n=(n+1)/(2n)\to1/2<1$ 确认绝对收敛，再令 $S = \sum_{n=1}^{\infty}\frac{n}{2^n}$，进行移项和相减。

$2S = \sum_{n=1}^{\infty}\frac{n}{2^{n-1}} = \sum_{n=0}^{\infty}\frac{n+1}{2^n} = 1+\sum_{n=1}^{\infty}\frac{n+1}{2^n} = 1+S+\sum_{n=1}^{\infty}\frac{1}{2^n} = 1+S+1 = S+2$

$2S = S+2$，$S = 2$

> **方法**：错位相减法，等比级数求和的推广。

## 四、Fourier级数

### 4.1 Dirichlet条件

将 $f$ 作 $2\pi$ 周期延拓，端点处取延拓后的左右极限。常用的一组充分条件是：
1. 连续或只有有限个第一类间断点
2. 只有有限个极值点

则Fourier级数收敛，且在连续点收敛到 $f(x)$，在间断点收敛到 $\frac{f(x+0)+f(x-0)}{2}$。

### 4.2 正弦级数与余弦级数

**奇延拓**（只含正弦项）：将 $[0,\pi]$ 上的函数延拓到 $[-\pi,\pi]$，再周期延拓
**偶延拓**（只含余弦项）：将 $[0,\pi]$ 上的函数作偶延拓，再周期延拓

**案例**：将 $f(x) = x$（$x \in [0,\pi]$）分别展为正弦级数和余弦级数。

**正弦级数**（奇延拓）：
$b_n = \frac{2}{\pi}\int_0^{\pi}x\sin nx\,dx = \frac{2}{\pi}\left[-\frac{x\cos nx}{n}\right]_0^{\pi}+\frac{2}{n\pi}\int_0^{\pi}\cos nx\,dx = \frac{2(-1)^{n+1}}{n}$

$x = 2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin nx$（$0<x<\pi$）。在 $x=\pi$ 处，周期延拓有跳跃，级数和为 0，并非 $\pi$；在 $x=0$ 处级数和为 0。

**余弦级数**（偶延拓）：
$$a_0=\frac{2}{\pi}\int_0^\pi x\,dx=\pi,\qquad a_n=\frac{2}{\pi}\int_0^\pi x\cos(nx)\,dx=\frac{2((-1)^n-1)}{\pi n^2}.$$
因此
$$x=\frac\pi2-\frac4\pi\sum_{k=0}^\infty\frac{\cos((2k+1)x)}{(2k+1)^2},\qquad 0\leq x\leq\pi.$$

**Parseval等式**（实函数 $f\in L^2[-\pi,\pi]$，$a_n,b_n$ 为其 Fourier 系数）：$\frac{a_0^2}{2}+\sum_{n=1}^{\infty}(a_n^2+b_n^2) = \frac{1}{\pi}\int_{-\pi}^{\pi}f^2(x)dx$

**应用**：对 $f(x)=x$（$0<x<\pi$）的正弦级数 $b_n = \frac{2(-1)^{n+1}}{n}$，用正弦级数版 Parseval 等式 $\sum_{n=1}^{\infty}b_n^2 = \frac{2}{\pi}\int_0^{\pi}f^2(x)dx$：

$4\sum_{n=1}^{\infty}\frac{1}{n^2} = \frac{2}{\pi}\int_0^{\pi}x^2dx = \frac{2\pi^2}{3}$

$\sum\frac{1}{n^2} = \frac{\pi^2}{6}$（Basel问题——Euler的伟大发现！）
