# 一元积分学详解

## 一、不定积分深化

### 1.1 三角函数积分

**类型一**：$\int \sin^m x\cos^n x\,dx$

| 情况 | 方法 |
|------|------|
| $m$ 为奇数 | 凑 $\sin x$，令 $u=\cos x$ |
| $n$ 为奇数 | 凑 $\cos x$，令 $u=\sin x$ |
| $m,n$ 均偶数 | 降幂公式 $\sin^2x=\frac{1-\cos 2x}{2}$ |

**类型二**：$\int \tan^m x\sec^n x\,dx$

| 情况 | 方法 |
|------|------|
| $n$ 为偶数 | 凑 $\sec x\tan x$，令 $u=\sec x$ |
| $m$ 为奇数 | 凑 $\sec^2 x$，令 $u=\tan x$ |

### 1.2 有理函数积分

$\int\frac{P(x)}{Q(x)}dx$：部分分式分解

**步骤**：
1. 若 $\deg P \geq \deg Q$，先做多项式除法
2. 将 $\frac{P}{Q}$ 分解为部分分式
3. 分别积分

**部分分式类型**：

| 分母因子 | 部分分式 | 积分结果 |
|----------|----------|----------|
| $(x-a)$ | $\frac{A}{x-a}$ | $A\ln\|x-a\|$ |
| $(x-a)^k$ | $\frac{A_1}{x-a}+\cdots+\frac{A_k}{(x-a)^k}$ | 对数+有理 |
| $(x^2+px+q)$（不可约） | $\frac{Ax+B}{x^2+px+q}$ | 对数+反正切 |
| $(x^2+px+q)^k$ | 递推 | 逐步降次 |

**案例**：$\int\frac{x+1}{x^2-x-6}dx$

$x^2-x-6 = (x-3)(x+2)$

$\frac{x+1}{(x-3)(x+2)} = \frac{A}{x-3}+\frac{B}{x+2}$

$x+1 = A(x+2)+B(x-3)$

$x=3$：$4=5A$，$A=4/5$
$x=-2$：$-1=-5B$，$B=1/5$

$\int\frac{x+1}{x^2-x-6}dx = \frac{4}{5}\ln|x-3|+\frac{1}{5}\ln|x+2|+C$

### 1.3 经典难题案例

**$\int e^{ax}\sin bx\,dx$**

$I = \int e^{ax}\sin bx\,dx$

分部积分：$u=\sin bx$，$dv=e^{ax}dx$
$I = \frac{1}{a}e^{ax}\sin bx - \frac{b}{a}\int e^{ax}\cos bx\,dx$

再分部：$I = \frac{1}{a}e^{ax}\sin bx - \frac{b}{a}\left(\frac{1}{a}e^{ax}\cos bx+\frac{b}{a}\int e^{ax}\sin bx\,dx\right)$

$I = \frac{1}{a}e^{ax}\sin bx - \frac{b}{a^2}e^{ax}\cos bx - \frac{b^2}{a^2}I$

$(1+\frac{b^2}{a^2})I = \frac{e^{ax}}{a^2}(a\sin bx - b\cos bx)$

$I = \frac{e^{ax}}{a^2+b^2}(a\sin bx - b\cos bx)+C$

> **复数法**：$e^{ax}\sin bx = \text{Im}(e^{(a+ib)x})$，积分后取虚部，一步到位。

## 二、定积分

### 2.1 定积分的性质

| 性质 | 内容 |
|------|------|
| 线性性 | $\int_a^b(k_1f+k_2g)dx = k_1\int f + k_2\int g$ |
| 区间可加 | $\int_a^b = \int_a^c + \int_c^b$ |
| 保号性 | $f \geq 0 \Rightarrow \int f \geq 0$ |
| 估值 | $m(b-a) \leq \int_a^b f \leq M(b-a)$ |
| 积分中值定理 | $\exists\xi\in[a,b]$，$\int_a^b f = f(\xi)(b-a)$ |

### 2.2 特殊技巧

**对称区间**：$\int_{-a}^a f(x)dx = \int_0^a[f(x)+f(-x)]dx$

- $f$ 奇函数：$\int_{-a}^a = 0$
- $f$ 偶函数：$\int_{-a}^a = 2\int_0^a$

**周期函数**：$\int_a^{a+T}f(x)dx = \int_0^T f(x)dx$

**Wallis公式**：
$$\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx = \frac{(n-1)!!}{n!!}\cdot\begin{cases}\frac{\pi}{2}, & n\text{偶}\\1, & n\text{奇}\end{cases}$$

### 2.3 反常积分判敛

**p-判别法**（无穷区间）：$\int_1^{+\infty}\frac{1}{x^p}dx$ 收敛当且仅当 $p > 1$

**p-判别法**（瑕积分，瑕点在0）：$\int_0^1\frac{1}{x^p}dx$ 收敛当且仅当 $p < 1$

**比较判别法**：若 $0 \leq f(x) \leq g(x)$ 且 $\int g$ 收敛，则 $\int f$ 收敛

**极限判别法**：$\lim_{x\to+\infty}x^p f(x) = c$
- $c > 0$，$p > 1$：收敛
- $c > 0$，$p \leq 1$：发散
- $c = 0$，$p > 1$：收敛

**案例**：$\int_1^{+\infty}\frac{\ln x}{x^2}dx$

$\lim_{x\to\infty}x^{3/2}\frac{\ln x}{x^2} = \lim\frac{\ln x}{\sqrt{x}} = 0$（L'Hôpital）

$p = 3/2 > 1$，$c = 0$，收敛。

实际计算：$\int_1^{+\infty}\frac{\ln x}{x^2}dx = \left[-\frac{\ln x}{x}\right]_1^{+\infty}+\int_1^{+\infty}\frac{1}{x^2}dx = 0+1 = 1$

### 2.4 Gamma函数与Beta函数

**Gamma函数**：$\Gamma(s) = \int_0^{+\infty}t^{s-1}e^{-t}dt$（$s > 0$）

**性质**：
- $\Gamma(s+1) = s\Gamma(s)$（递推公式）
- $\Gamma(n) = (n-1)!$（正整数时退化为阶乘）
- $\Gamma(1/2) = \sqrt{\pi}$（Gauss积分）

**Beta函数**：$B(p,q) = \int_0^1 t^{p-1}(1-t)^{q-1}dt$

**关系**：$B(p,q) = \frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$

> **与概率论的联系**：Gamma分布的归一化常数 = $\Gamma(\alpha)/\beta^\alpha$，Beta分布的归一化常数 = $1/B(\alpha,\beta)$。
