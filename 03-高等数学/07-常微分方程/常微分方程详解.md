# 常微分方程详解

## 一、一阶微分方程

### 1.1 可分离变量型

$y' = f(x)g(y)$

解法：在 $g(y)\neq0$ 的区间上，$\int\frac{dy}{g(y)} = \int f(x)dx$。还须将 $g(c)=0$ 给出的常值解 $y\equiv c$ 单独补回。

**案例**：$y' = \frac{x}{y}$

$y\,dy = x\,dx$，$\frac{y^2}{2} = \frac{x^2}{2}+C$，$y^2 = x^2+2C$

显式解为 $y=\pm\sqrt{x^2+2C}$，应在 $x^2+2C>0$ 的连通区间上固定一个符号；原方程在 $y=0$ 无定义，隐式关系上的零点不能直接纳入解区间。

### 1.2 齐次方程

$y' = \varphi\left(\frac{y}{x}\right)$

令 $u = \frac{y}{x}$，$y = ux$，$y' = u+xu'$

$xu' = \varphi(u)-u$（可分离变量）

### 1.3 一阶线性方程

$y' + P(x)y = Q(x)$

以下假设 $P,Q$ 在同一讨论区间连续。

**通解公式**：
$$y = e^{-\int Pdx}\left[\int Qe^{\int Pdx}dx+C\right]$$

**推导**（积分因子法）：

方程两边乘 $e^{\int Pdx}$：
$y'e^{\int Pdx}+Pye^{\int Pdx} = Qe^{\int Pdx}$

左边 = $(ye^{\int Pdx})' = Qe^{\int Pdx}$

积分：$ye^{\int Pdx} = \int Qe^{\int Pdx}dx+C$

**案例**：$y'+y = e^{-x}$

$P=1$，$Q=e^{-x}$，$\int Pdx = x$

$y = e^{-x}\left[\int e^{-x}\cdot e^x dx+C\right] = e^{-x}[x+C]$

### 1.4 Bernoulli方程

$y'+P(x)y = Q(x)y^n$（$n \neq 0,1$）

令 $z = y^{1-n}$：

$\frac{dz}{dx} = (1-n)y^{-n}y' = (1-n)y^{-n}[Qy^n-Py]$

$z'+(1-n)Pz = (1-n)Q$

化为一阶线性方程。此代换在 $y\neq0$ 且实数幂有定义的区间内使用；例如 $n>0$ 时还须检查原方程的零解。

## 二、高阶线性微分方程

### 2.1 解的结构

在一个区间内，若线性方程各系数和非齐次项连续，且最高阶系数处处非零，则归一化后的 $n$ 阶方程有以下解结构。

**齐次** $Ly = 0$：解空间维数 = $n$（方程阶数）
**非齐次** $Ly = f$：通解 = 齐次通解 + 一个特解

> **与线性代数的完全对应**：$L$ 是线性算子，解空间是向量空间。非齐次方程的解集 = 齐次解空间 + 特解平移（仿射空间）。

### 2.2 二阶常系数齐次方程

$y''+py'+qy = 0$

特征方程 $r^2+pr+q = 0$

| 根 | 通解 |
|----|------|
| $r_1 \neq r_2$（实） | $C_1 e^{r_1 x}+C_2 e^{r_2 x}$ |
| $r_1 = r_2 = r$ | $(C_1+C_2 x)e^{rx}$ |
| $\alpha \pm i\beta$ | $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |

### 2.3 二阶常系数非齐次方程

$y''+py'+qy = f(x)$

**特解的待定系数法**：

| $f(x)$ | 特解形式 | 注意 |
|----------|----------|------|
| $e^{\lambda x}P_m(x)$ | $x^k e^{\lambda x}Q_m(x)$ | $k$ = $\lambda$ 是特征根的重数 |
| $e^{\lambda x}(a\cos\omega x+b\sin\omega x)$ | $x^k e^{\lambda x}(A\cos\omega x+B\sin\omega x)$ | $k$ = $\lambda\pm i\omega$ 是特征根的重数 |

**案例**：$y''-3y'+2y = e^x$

齐次通解：特征方程 $r^2-3r+2=0$，$r_1=1,r_2=2$

$Y = C_1 e^x+C_2 e^{2x}$

$f(x) = e^x$，$\lambda=1$ 是单根，$k=1$

设特解 $y^* = Axe^x$

$y^{*'} = Ae^x+Axe^x = A(1+x)e^x$

$y^{*''} = A(2+x)e^x$

代入：$A(2+x)e^x-3A(1+x)e^x+2Axe^x = e^x$

$A[(2+x)-3(1+x)+2x] = 1$

$A[-1] = 1$，$A = -1$

$y^* = -xe^x$

通解：$y = C_1 e^x+C_2 e^{2x}-xe^x$

### 2.4 Euler方程

$x^2y''+pxy'+qy = f(x)$

**代换**：在 $x>0$ 上取 $x=e^t$；在 $x<0$ 上取 $x=-e^t$，统一记 $t=\ln|x|$。$x=0$ 为奇点，须另行讨论。

$x\frac{dy}{dx} = \frac{dy}{dt}$，$x^2\frac{d^2y}{dx^2} = \frac{d^2y}{dt^2}-\frac{dy}{dt}$

化为常系数方程求解。

## 三、微分方程的应用

### 3.1 物理应用

**弹簧-质量系统**：$mx''+cx'+kx = F(t)$

$m=1, c=0, k=4, F=0$：$x''+4x = 0$

特征方程 $r^2+4=0$，$r = \pm 2i$

$x(t) = C_1\cos 2t+C_2\sin 2t = A\sin(2t+\phi)$

简谐运动，周期 $T = \pi$。

### 3.2 混合问题

水池100L，含盐10kg。以5L/min注入含盐0.2kg/L的盐水，同时以5L/min流出。假设池内始终充分混匀，求 $t\geq0$ 时刻含盐量。

$\frac{dQ}{dt} = \text{流入速率} - \text{流出速率} = 5\times 0.2 - 5\times\frac{Q}{100} = 1-\frac{Q}{20}$

$\frac{dQ}{dt}+\frac{Q}{20} = 1$

一阶线性方程：$Q = 20+Ce^{-t/20}$

$Q(0) = 10$：$C = -10$，$Q(t) = 20-10e^{-t/20}$

$\lim_{t\to\infty}Q(t) = 20$ kg（平衡态）
