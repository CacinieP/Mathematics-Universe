# 向量代数与空间解析几何详解

## 一、向量代数

### 1.1 数量积（内积）

$\mathbf{a}\cdot\mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta = a_1b_1+a_2b_2+a_3b_3$

**性质**：
- 交换律：$\mathbf{a}\cdot\mathbf{b}=\mathbf{b}\cdot\mathbf{a}$
- 正交性：$\mathbf{a}\cdot\mathbf{b}=0$ ⟺ $\mathbf{a}\perp\mathbf{b}$
- 投影：$\text{proj}_{\mathbf{b}}\mathbf{a} = \frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{b}|^2}\mathbf{b}$

### 1.2 向量积（外积）

$\mathbf{a}\times\mathbf{b} = \begin{vmatrix}\mathbf{i}&\mathbf{j}&\mathbf{k}\\a_1&a_2&a_3\\b_1&b_2&b_3\end{vmatrix}$

**性质**：
- $|\mathbf{a}\times\mathbf{b}| = |\mathbf{a}||\mathbf{b}|\sin\theta$（平行四边形面积）
- 方向：右手定则
- 反交换：$\mathbf{a}\times\mathbf{b} = -\mathbf{b}\times\mathbf{a}$
- 平行：$\mathbf{a}\times\mathbf{b} = \mathbf{0}$ ⟺ $\mathbf{a}\parallel\mathbf{b}$

### 1.3 混合积

$[\mathbf{a}\,\mathbf{b}\,\mathbf{c}] = \mathbf{a}\cdot(\mathbf{b}\times\mathbf{c}) = \begin{vmatrix}a_1&a_2&a_3\\b_1&b_2&b_3\\c_1&c_2&c_3\end{vmatrix}$

**几何意义**：平行六面体的有向体积。

$[\mathbf{a}\,\mathbf{b}\,\mathbf{c}] = 0$ ⟺ 三向量共面。

> **与线性代数的联系**：混合积 = 3×3行列式。行列式为0 ⟺ 三向量线性相关（共面）。

## 二、空间直线与平面

### 2.1 平面方程

- 一般式：$Ax+By+Cz+D=0$，法向量 $\mathbf{n}=(A,B,C)$
- 点法式：$A(x-x_0)+B(y-y_0)+C(z-z_0)=0$
- 截距式：$\frac{x}{a}+\frac{y}{b}+\frac{z}{c}=1$

### 2.2 直线方程

- 一般式：两个平面的交线
- 参数式：$\mathbf{r} = \mathbf{r}_0+t\mathbf{d}$
- 对称式：$\frac{x-x_0}{l}=\frac{y-y_0}{m}=\frac{z-z_0}{n}$

### 2.3 距离公式

| 距离 | 公式 |
|------|------|
| 点到平面 | $d = \frac{|Ax_0+By_0+Cz_0+D|}{\sqrt{A^2+B^2+C^2}}$ |
| 点到直线 | $d = \frac{|\overrightarrow{P_0P}\times\mathbf{d}|}{|\mathbf{d}|}$ |
| 异面直线 | $d = \frac{|(\mathbf{d_1}\times\mathbf{d_2})\cdot\overrightarrow{P_1P_2}|}{|\mathbf{d_1}\times\mathbf{d_2}|}$ |

## 三、空间曲面

### 3.1 旋转曲面

$yOz$ 面上曲线 $f(y,z)=0$ 绕 $z$ 轴旋转：$f(\pm\sqrt{x^2+y^2},z)=0$

**案例**：$y=z^2$ 绕 $z$ 轴旋转

$x^2+y^2 = z^4$（旋转抛物面）

### 3.2 柱面

只含两个变量的方程在空间中表示柱面。

$x^2+y^2=R^2$：圆柱面（母线平行于 $z$ 轴）
