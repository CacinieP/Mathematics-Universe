# 多元积分学详解

## 一、二重积分

### 1.1 计算方法

以下有界区域取分片光滑边界，并可假设被积函数连续；在无界区域或有奇点时，交换积分顺序需核对绝对可积性，或使用非负函数的 Tonelli 定理。

**直角坐标**：

若 $D = \{(x,y)|a \leq x \leq b, \varphi_1(x) \leq y \leq \varphi_2(x)\}$（X-型区域）：
$$\iint_D f\,dxdy = \int_a^b dx\int_{\varphi_1(x)}^{\varphi_2(x)}f(x,y)dy$$

若 $D = \{(x,y)|c \leq y \leq d, \psi_1(y) \leq x \leq \psi_2(y)\}$（Y-型区域）：
$$\iint_D f\,dxdy = \int_c^d dy\int_{\psi_1(y)}^{\psi_2(y)}f(x,y)dx$$

**极坐标**：$x = r\cos\theta$，$y = r\sin\theta$
$$\iint_D f\,dxdy = \iint_{D'} f(r\cos\theta,r\sin\theta)r\,drd\theta$$

### 1.2 交换积分顺序

**案例**：交换 $\int_0^1 dx\int_x^1 e^{-y^2}dy$ 的积分顺序

原顺序：先对 $y$ 积分，$e^{-y^2}$ 没有初等原函数。

改写区域：$D = \{0 \leq x \leq 1, x \leq y \leq 1\} = \{0 \leq y \leq 1, 0 \leq x \leq y\}$

$$= \int_0^1 dy\int_0^y e^{-y^2}dx = \int_0^1 ye^{-y^2}dy = \left[-\frac{1}{2}e^{-y^2}\right]_0^1 = \frac{1}{2}(1-e^{-1})$$

> **技巧**：当内层积分积不出来时，考虑交换顺序。

### 1.3 对称性利用

- $D$ 关于 $x$ 轴对称：$f(x,-y) = f(x,y)$（$y$偶）⟹ $\iint_D = 2\iint_{D_{上半}}$；$f(x,-y) = -f(x,y)$（$y$奇）⟹ $\iint_D = 0$
- $D$ 关于 $y$ 轴对称：类似
- $D$ 关于 $y=x$ 对称：$\iint_D f(x,y)dxdy = \iint_D f(y,x)dxdy$

**案例**：$\iint_D (x^2+y^2)dxdy$，$D$: $x^2+y^2 \leq R^2$

极坐标：$= \int_0^{2\pi}d\theta\int_0^R r^2 \cdot r\,dr = 2\pi \cdot \frac{R^4}{4} = \frac{\pi R^4}{2}$

## 二、三重积分

### 2.1 坐标系选择

| 坐标系 | 适用区域 | 体积元素 |
|--------|----------|----------|
| 直角坐标 | 立方体、长方体 | $dxdydz$ |
| 柱坐标 $(r,\theta,z)$ | 圆柱、旋转体 | $r\,drd\theta dz$ |
| 球坐标 $(r,\varphi,\theta)$ | 球、圆锥 | $r^2\sin\varphi\,drd\varphi d\theta$ |

### 2.2 案例：球体积

$V = \iiint_{x^2+y^2+z^2\leq R^2}dV$

球坐标：$r \in [0,R]$，$\varphi \in [0,\pi]$，$\theta \in [0,2\pi]$

$V = \int_0^{2\pi}\int_0^{\pi}\int_0^R r^2\sin\varphi\,drd\varphi d\theta = 2\pi \cdot 2 \cdot \frac{R^3}{3} = \frac{4\pi R^3}{3}$

## 三、曲线积分

### 3.1 第一类（对弧长）

$$\int_L f(x,y)ds = \int_\alpha^\beta f(x(t),y(t))\sqrt{x'^2(t)+y'^2(t)}dt$$

**与路径方向无关**。

### 3.2 第二类（对坐标）

$$\int_L Pdx+Qdy = \int_\alpha^\beta [P x'(t)+Q y'(t)]dt$$

**与路径方向有关**（反向取负）。

### 3.3 Green公式

$$\oint_L Pdx+Qdy = \iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dxdy$$

条件：$D$ 为有界平面区域，边界 $L$ 分片光滑并取正向（外边界逆时针、孔洞边界顺时针），$P,Q$ 在包含 $\overline D$ 的开邻域内有连续一阶偏导。

**应用**：
1. 化曲线积分为二重积分
2. 求面积：$A = \frac{1}{2}\oint_L xdy-ydx$

**路径无关条件**（在**单连通**区域内且 $P,Q$ 有连续一阶偏导时等价）：
- $\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$（处处成立）
- $\oint_C Pdx+Qdy = 0$（任意闭曲线）
- $Pdx+Qdy$ 是某函数的全微分
- 积分与路径无关

> **反例**：$\frac{-y\,dx+x\,dy}{x^2+y^2}$ 在去掉原点的区域内满足 $\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}$，但绕原点一周的积分为 $2\pi$——单连通性不可去。

## 四、曲面积分

### 4.1 Gauss公式（散度定理）

$$\iint_S \mathbf{F}\cdot d\mathbf{S} = \iiint_V \nabla\cdot\mathbf{F}\,dV$$

**条件**：$V$ 为有界区域，$S=\partial V$ 是分片光滑的外向封闭边界；$\mathbf F$ 在包含 $\overline V$ 的开邻域内一阶连续可微。

### 4.2 Stokes公式

$$\oint_L \mathbf{F}\cdot d\mathbf{r} = \iint_S(\nabla\times\mathbf{F})\cdot d\mathbf{S}$$

**条件**：$S$ 为可定向的分片光滑曲面，$L=\partial S$ 按所选法向取右手正向，$\mathbf F$ 在包含 $S$ 的开邻域内一阶连续可微。

### 4.3 三大公式统一（广义Stokes定理）

$$\int_{\partial M}\omega = \int_M d\omega$$

| 维度 | 公式 | $\omega$ |
|------|------|----------|
| 1维 | Newton-Leibniz | $F(x)$ |
| 2维 | Green | $Pdx+Qdy$ |
| 2维曲面（嵌入3维空间）| Stokes | $Pdx+Qdy+Rdz$ |
| 3维（体）| Gauss | $Pdy\wedge dz+Qdz\wedge dx+Rdx\wedge dy$ |

> **数学的统一性**：四个看似不同的公式其实是同一个定理在不同维度下的表现。
