# 复变函数与解析——超纲但深刻

> 工科数学很少直接用到复分析，但复分析的思想渗透到数学的每一个角落。理解它，你就理解了为什么数学是一个整体。

## 一、为什么需要复数

### 1.1 从实数到复数的历史

1. **16世纪**：Cardano在解三次方程时发现需要对负数开平方
2. **18世纪**：Euler引入符号 $i = \sqrt{-1}$，发现 $e^{i\pi} + 1 = 0$
3. **19世纪**：Gauss、Cauchy、Riemann建立复分析

### 1.2 复数的代数意义

没有复数，以下事实无法解释：
- $x^2 + 1 = 0$ 在 $\mathbb{R}$ 中无解，但在 $\mathbb{C}$ 中有解 $\pm i$
- **代数基本定理**：$n$ 次复系数多项式恰好有 $n$ 个复根（计重数）
- 实系数多项式的复根成共轭对出现

### 1.3 复数的几何意义

$z = x + iy \leftrightarrow (x, y)$：复数 = 平面上的点。

运算的几何意义：
- 加法 = 向量加法
- 乘法 = 模相乘 + 辐角相加（旋转+伸缩）
- 共轭 = 关于实轴对称
- 模 $|z| = \sqrt{x^2+y^2}$ = 到原点距离

## 二、解析函数——复变函数的核心

### 2.1 复变函数

$f: \mathbb{C} \to \mathbb{C}$，即 $w = f(z)$

写成 $f(z) = u(x,y) + iv(x,y)$，其中 $z = x+iy$。

### 2.2 解析性

**定义**：$f$ 在 $z_0$ 可导指极限 $\lim_{\Delta z \to 0}\frac{f(z_0+\Delta z)-f(z_0)}{\Delta z}$ 存在。

**注意**：$\Delta z \to 0$ 是在平面上以**任意方式**趋于0。这比一元实函数的导数条件强得多。

**Cauchy-Riemann方程**：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

$f$ 解析 ⟺ 满足C-R方程且偏导数连续。

### 2.3 解析函数的惊人性质

解析函数比实可微函数"好"得多：

| 性质 | 实函数 | 解析函数 |
|------|--------|----------|
| 可导 ⟹ 连续 | 是 | 是 |
| 可导 ⟹ 可导任意次 | 否（如 $f(x)=x^{3/2}$） | **是！** |
| 知道局部值 ⟹ 确定全局 | 否 | **是（解析延拓）** |
| Taylor级数收敛到自身 | 不一定（如 $e^{-1/x^2}$） | **总是** |

解析函数是"被上帝宠爱的函数"——知道一点点就知道全部。

### 2.4 Cauchy积分定理

**定理**：若 $f$ 在单连通区域 $D$ 内解析，$C$ 是 $D$ 内的简单闭曲线，则：
$$\oint_C f(z)dz = 0$$

这个定理是复分析的基础，由它可以推出：
- Cauchy积分公式
- Taylor展开
- Liouville定理
- 最大模原理

### 2.5 Cauchy积分公式

$$f(z_0) = \frac{1}{2\pi i}\oint_C \frac{f(z)}{z-z_0}dz$$

**含义**：解析函数在区域内部的值，完全由边界上的值决定。

**推广**（高阶导数）：
$$f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz$$

解析函数可导任意次，且各阶导数由边界值完全确定。

## 三、与实分析的对照

### 3.1 积分的统一

| 实积分 | 复积分 |
|--------|--------|
| $\int_a^b f(x)dx$ | $\int_C f(z)dz$ |
| 沿实轴 | 沿平面曲线 |
| Newton-Leibniz | Cauchy定理（无原函数时也可以算！） |
| 换元法 | 留数定理 |

### 3.2 留数定理——计算实积分的神器

$$\oint_C f(z)dz = 2\pi i \sum_k \text{Res}(f, z_k)$$

其中求和是对 $C$ 内的所有奇点。

**经典应用**：

计算 $\int_0^{2\pi}\frac{d\theta}{a+\cos\theta}$（$a > 1$）

令 $z = e^{i\theta}$，则 $d\theta = \frac{dz}{iz}$，$\cos\theta = \frac{z+z^{-1}}{2}$

$$= \oint_{|z|=1}\frac{dz}{iz\left(a+\frac{z+z^{-1}}{2}\right)} = \oint_{|z|=1}\frac{2dz}{i(z^2+2az+1)}$$

用留数定理计算单位圆内的极点留数即可。

### 3.3 $e^{i\theta} = \cos\theta + i\sin\theta$ 的深刻含义

Euler公式不仅是"一个公式"，它揭示了：
- **指数函数和三角函数是同一个东西在实轴和虚轴上的投影**
- **双曲函数和三角函数也是同一个东西**：$\cos(iz) = \cosh(z)$
- **微分方程**：$y'' + y = 0$ 的解是 $A\cos t + B\sin t = Ce^{it} + De^{-it}$

## 四、与工科数学的联系

### 4.1 信号处理

- Laplace变换 = 复平面上的Fourier变换
- 系统稳定性 = 极点是否在左半平面
- 频率响应 = 沿虚轴的Laplace变换

### 4.2 控制理论

- 传递函数 $G(s) = \frac{Y(s)}{U(s)}$ 是 $s$（复变量）的有理函数
- 稳定性 ⟺ 极点全部在左半平面（实部为负）

### 4.3 流体力学

- 二维无旋不可压流 = 复位势（解析函数的实部或虚部）
- 保角映射 = 解析函数的几何效应

### 4.4 量子力学

- 波函数 $\psi(x,t)$ 是复值函数
- Schrödinger方程 $i\hbar\frac{\partial\psi}{\partial t} = H\psi$ 含有虚数单位 $i$
- 概率 = $|\psi|^2$ = 模的平方
