# 复变函数与解析——超纲但深刻

> 复分析广泛用于电路、信号处理、控制和流体力学，其思想也连接着数学的许多分支。理解它，你就理解了为什么数学是一个整体。

## 一、为什么需要复数

### 1.1 从实数到复数的历史

1. **16世纪**：Cardano在解三次方程时发现需要对负数开平方
2. **18世纪**：Euler引入符号 $i = \sqrt{-1}$，发现 $e^{i\pi} + 1 = 0$
3. **19世纪**：Gauss、Cauchy、Riemann建立复分析

### 1.2 复数的代数意义

引入复数后，可以统一描述以下事实：
- $x^2 + 1 = 0$ 在 $\mathbb{R}$ 中无解，但在 $\mathbb{C}$ 中有解 $\pm i$
- **代数基本定理**：$n$ 次复系数多项式恰好有 $n$ 个复根（计重数）
- 实系数多项式的复根成共轭对出现

### 1.3 复数的几何意义

$z = x + iy \leftrightarrow (x, y)$：复数 = 平面上的点。

运算的几何意义：
- 加法 = 向量加法
- 乘法 = 模相乘 + 辐角相加（旋转+伸缩）
- 共轭 = 关于实轴对称
- 模 $|z| = \sqrt{x^2+y^2}$ = 到原点距离

## 二、解析函数——复变函数的核心

### 2.1 复变函数

$f: \mathbb{C} \to \mathbb{C}$，即 $w = f(z)$

写成 $f(z) = u(x,y) + iv(x,y)$，其中 $z = x+iy$。

### 2.2 解析性

**定义**：$f$ 在 $z_0$ 可导指极限 $\lim_{\Delta z \to 0}\frac{f(z_0+\Delta z)-f(z_0)}{\Delta z}$ 存在。

**解析（全纯）**：$f$ 在开集 $D$ 的每一点都复可导。仅在一个孤立点复可导不能推出在其邻域解析。

**注意**：$\Delta z \to 0$ 是在平面上以**任意方式**趋于0。这比一元实函数的导数条件强得多。

**Cauchy-Riemann方程**：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

在开集 $D$ 上，若 $u,v$ 的一阶偏导连续，则满足 C–R 方程等价于 $f$ 在 $D$ 上解析。对一个点而言，实可微且满足 C–R 方程即可推出复可导。参见 [MIT 18.04 复可导与解析讲义](https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-spring-2018/330e301bd727c7bdaa679cf44cb75fe3_MIT18_04S18_topic2.pdf)。

### 2.3 解析函数的惊人性质

解析函数比实可微函数"好"得多：

| 性质 | 实函数 | 解析函数 |
|------|--------|----------|
| 可导 ⟹ 连续 | 是 | 是 |
| 在邻域内可导 ⟹ 可导任意次 | 否（如 $f(x)=x\lvert x\rvert$ 在 0 处没有二阶导数） | **是** |
| 在一个开子集上相同 ⟹ 整个区域相同 | 否 | 同一连通域上的两个解析函数满足此结论（恒等定理） |
| Taylor级数收敛到自身 | 不一定（$e^{-1/x^2}$ 在 0 补成 0 是反例） | 在展开点周围的收敛圆内成立 |

恒等定理要求已知值的集合在定义域内部有聚点；单独知道一个点的函数值不够，也不保证函数能越过奇点继续解析延拓。

### 2.4 Cauchy积分定理

**定理**：若 $f$ 在单连通区域 $D$ 内解析，$C$ 是 $D$ 内的简单闭曲线，则：
$$\oint_C f(z)dz = 0$$

这个定理是复分析的基础，由它可以推出：
- Cauchy积分公式
- Taylor展开
- Liouville定理
- 最大模原理

### 2.5 Cauchy积分公式

设 $C$ 为正向、分片光滑的简单闭曲线，$f$ 在包含 $C$ 及其内部的开集上解析，$z_0$ 在 $C$ 内部。则：

$$f(z_0) = \frac{1}{2\pi i}\oint_C \frac{f(z)}{z-z_0}dz$$

**含义**：解析函数在区域内部的值，完全由边界上的值决定。

**推广**（高阶导数）：
$$f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz$$

解析函数可导任意次，且各阶导数由边界值完全确定。

## 三、与实分析的对照

### 3.1 积分的统一

| 实积分 | 复积分 |
|--------|--------|
| $\int_a^b f(x)dx$ | $\int_C f(z)dz$ |
| 沿实轴 | 沿平面曲线 |
| Newton-Leibniz | Cauchy定理（无原函数时也可以算！） |
| 换元法 | 留数定理 |

### 3.2 留数定理——计算实积分的神器

$$\oint_C f(z)dz = 2\pi i \sum_k \text{Res}(f, z_k)$$

这里 $C$ 为正向、分片光滑的简单闭曲线；$f$ 在曲线及内部除有限个孤立奇点 $z_k$ 外解析，且曲线上没有奇点。求和取内部奇点的留数。

**经典应用**：

计算 $\int_0^{2\pi}\frac{d\theta}{a+\cos\theta}$（$a > 1$）

令 $z = e^{i\theta}$，则 $d\theta = \frac{dz}{iz}$，$\cos\theta = \frac{z+z^{-1}}{2}$

$$= \oint_{|z|=1}\frac{dz}{iz\left(a+\frac{z+z^{-1}}{2}\right)} = \oint_{|z|=1}\frac{2dz}{i(z^2+2az+1)}$$

两个极点为 $z_\pm=-a\pm\sqrt{a^2-1}$，只有 $z_+$ 在单位圆内。其留数为 $1/(i\sqrt{a^2-1})$，故原积分为 $2\pi/\sqrt{a^2-1}$。

### 3.3 $e^{i\theta} = \cos\theta + i\sin\theta$ 的深刻含义

Euler公式不仅是"一个公式"，它揭示了：
- **指数函数和三角函数是同一个东西在实轴和虚轴上的投影**
- **双曲函数和三角函数也是同一个东西**：$\cos(iz) = \cosh(z)$
- **微分方程**：$y'' + y = 0$ 的解是 $A\cos t + B\sin t = Ce^{it} + De^{-it}$

## 四、与工科数学的联系

### 4.1 信号处理

- 双边 Laplace 变换在 $s=\sigma+i\omega$ 处，是 $e^{-\sigma t}f(t)$ 的 Fourier 变换（在相应收敛条件下）
- 连续时间因果有限维线性时不变系统的稳定性可由相应传递函数极点判断
- 当收敛域包含虚轴时，频率响应由 Laplace 变换取 $s=i\omega$ 得到

### 4.2 控制理论

- 连续时间有限维线性时不变系统在零初始条件下，传递函数 $G(s)=Y(s)/U(s)$ 为有理函数
- 对因果、适当的有理传递函数，BIBO 稳定要求其极点全部在开左半平面；非最小实现的内部稳定性还需检查被零极点相消隐藏的模态

### 4.3 流体力学

- 二维无旋、不可压流在适当的单连通区域内可用解析的复位势描述，其实部为速度势、虚部为流函数
- 解析函数在导数非零的点局部保角；导数为零的点不能直接套用

### 4.4 量子力学

- 波函数 $\psi(x,t)$ 是复值函数
- Schrödinger方程 $i\hbar\frac{\partial\psi}{\partial t} = H\psi$ 含有虚数单位 $i$
- 位置概率密度 = $|\psi|^2$；区域内概率为其在该区域的积分（波函数须归一化）
