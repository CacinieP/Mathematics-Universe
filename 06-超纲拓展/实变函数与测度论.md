# 实变函数与测度论——积分的革命

> Lebesgue积分不是Riemann积分的替代，而是它的推广。在测度论的视角下，概率、积分、长度、面积、体积都有了统一的语言。

## 一、为什么需要测度论

### 1.1 Riemann积分的局限

**Riemann积分**：对定义域做分割，在每个小区间上取函数值的近似。

**失败案例**：Dirichlet函数
$$D(x) = \begin{cases}1, & x \in \mathbb{Q}\\0, & x \notin \mathbb{Q}\end{cases}$$

在 $[0,1]$ 上，$D(x)$ 的Riemann积分**不存在**（上和=1，下和=0）。

但从直觉上，有理数的"长度"应该是0（可数集"几乎不占空间"），所以 $D(x)$ 的积分"应该是0"。

### 1.2 Lebesgue的革命性思想

**Riemann**：分割 $x$ 轴（定义域），在每个小区间上取函数值
**Lebesgue**：分割 $y$ 轴（值域），对每个函数值找原像的"长度"

$$\int f\,d\mu = \lim_{n\to\infty}\sum_{k} y_k \cdot \mu(f^{-1}([y_k, y_{k+1})))$$

关键问题：$\mu(f^{-1}([y_k, y_{k+1})))$ 是什么？这就需要**测度**。

## 二、Lebesgue测度

### 2.1 测度的定义

**外测度**：
$$\mu^*(E) = \inf\left\{\sum_{i=1}^{\infty}|I_i| : E \subset \bigcup I_i\right\}$$

用开区间覆盖 $E$，取总长度的下确界。

**Lebesgue可测**：$\forall A \subset \mathbb{R}$，$\mu^*(A) = \mu^*(A\cap E) + \mu^*(A\setminus E)$（Carathéodory条件）

### 2.2 关键结果

| 集合 | 测度 |
|------|------|
| $[a,b]$ | $b-a$ |
| 可数集（如 $\mathbb{Q}$） | 0 |
| Cantor集 | 0（虽然不可数！） |
| 不可测集 | 存在（Vitali集，依赖选择公理） |

### 2.3 测度与概率的统一

| 测度论 | 概率论 |
|--------|--------|
| 测度空间 $(\Omega, \mathcal{F}, \mu)$ | 概率空间 $(\Omega, \mathcal{F}, P)$ |
| $\mu(\Omega)$ 可以是 $+\infty$ | $P(\Omega) = 1$ |
| 可测函数 | 随机变量 |
| $\int f\,d\mu$ | $E[X]$ |
| 几乎处处(a.e.) | 几乎必然(a.s.) |

**概率 = 归一化的测度。** 概率论是测度论的特殊情形。

## 三、Lebesgue积分

### 3.1 构造过程

1. **简单函数**：$\phi = \sum c_k \mathbf{1}_{E_k}$，$\int\phi\,d\mu = \sum c_k\mu(E_k)$
2. **非负可测函数**：$\int f\,d\mu = \sup\{\int\phi\,d\mu : \phi \leq f, \phi \text{ 简单}\}$
3. **一般可测函数**：$f = f^+ - f^-$，$\int f = \int f^+ - \int f^-$

### 3.2 三大收敛定理

**单调收敛定理**：$f_n \geq 0$，$f_n \uparrow f$ → $\int f_n \to \int f$

**Fatou引理**：$f_n \geq 0$ → $\int\liminf f_n \leq \liminf\int f_n$

**控制收敛定理**：$|f_n| \leq g$（$g$ 可积），$f_n \to f$ a.e. → $\int f_n \to \int f$

**概率论对应**：
- 单调收敛 → 期望的单调性
- Fatou引理 → 期望的下连续性 E[liminf Xₙ] ≤ liminf E[Xₙ]（Markov 不等式由积分单调性直接可得，并非 Fatou 引理的推论）
- 控制收敛 → "积分号下取极限"

### 3.3 与Riemann积分的关系

**定理**：若 $f$ 在 $[a,b]$ 上Riemann可积，则 $f$ Lebesgue可积，且两个积分值相等。

反之不成立：Dirichlet函数Lebesgue可积（=0）但Riemann不可积。

**Lebesgue积分是Riemann积分的真推广。**

## 四、$L^p$ 空间

### 4.1 定义

$$L^p(\mu) = \{f : \|f\|_p = (\int|f|^p\,d\mu)^{1/p} < \infty\}$$

### 4.2 重要不等式

**Hölder不等式**：$f \in L^p, g \in L^q$（$\frac{1}{p}+\frac{1}{q}=1$）→ $fg \in L^1$，$\|fg\|_1 \leq \|f\|_p\|g\|_q$

**Minkowski不等式**：$\|f+g\|_p \leq \|f\|_p + \|g\|_p$

**概率论中的Hölder**：$E[|XY|] \leq (E[|X|^p])^{1/p}(E[|Y|^q])^{1/q}$

$p=q=2$ 时就是**Cauchy-Schwarz不等式**。

### 4.3 与线性代数的统一

$L^2$ 是**Hilbert空间**（完备的内积空间），内积为 $\langle f,g\rangle = \int f\bar{g}\,d\mu$。

- 正交 = 内积为零
- Fourier系数 = 在正交基上的投影
- Parseval恒等式 = 勾股定理

有限维向量空间 → 无穷维函数空间，线性代数的语言完全适用。
