### 条件与边界补强

1. 反函数定义在值域，整个陪域上存在反函数还需满射。
2. 奇偶积分、周期积分的可积性；反常积分不能仅凭奇性取零。
3. Cauchy积分形式、函数内积与Parseval限定实函数、平方可积及L²几乎处处等价类。
4. 指数函数底数、无理幂实定义域。
5. Hilbert空间必须具有内积诱导范数的完备性。
6. 圆锥曲线参数、圆的e=0情形、有限准线定义的限制。
7. 点到平面公式点位、非零法向量/方向向量、截距式非零有限截距。
8. 乘法计数要求每一步的选择数不随先前具体选择改变。
9. 交错二项式系数和在n=0时为1。
10. 条件概率乘法公式每个条件事件须概率为正。
11. 描述数据的分母n方差与无偏样本方差n−1口径。
12. 密度乘小区间是连续密度处的一阶近似，不是单点概率。
13. Buffon投针要求位置和角度均匀且独立；硬币、骰子和信封例题补全抽样模型。
14. 均匀、指数、Gamma、离散分布及超几何分布的支持集和参数范围。
15. 保不等式极限须两序列均收敛。
16. 1的无穷次幂速算须底数正、指数乘积极限存在，并约定无穷极限。
17. 铅直渐近线允许单侧无穷；斜渐近线的k、b须有限且k非零。
18. 曲率为0时不存在有限曲率半径。
19. Wallis公式的非负整数n及0!!=(-1)!!=1约定。
20. 多元链式法则需要可微，不只存在偏导数。
21. Lagrange法只给候选点；补全xy最大性的全局验证。
22. 坐标换元明确复合函数、区域、Jacobi、内部一一覆盖及球坐标角度约定。
23. 曲线积分的正则分段参数、广义Stokes的定向/光滑/紧致充分条件。
24. 幂级数比值半径公式要求尾部系数非零，Cauchy–Hadamard的0/∞约定。
25. C∞不保证Taylor级数还原函数；新增e^(−1/x²)平坦函数反例。
26. 无穷级数错位相减前先证明绝对收敛。
27. ODE y′=x/y显式分支和y≠0解区间，一阶线性方程系数连续。
28. 盐水混合模型要求始终充分混匀。
29. 少一个坐标的方程也可能空集或低维退化，不能一概称普通柱面。
30. 三对角递推初值D0=1、D1=a及重复零根；矩阵等价要求同型、特征值按数域和代数重数解释。
31. 二维正态非退化条件、零线性组合和|rho|=1条件分布点质量。
32. 置信区间的频率学派覆盖率、卡方枢轴量、Z检验已知标准差条件。
33. 已知sigma的样本量宽度保证与用预估sigma进行规划的区别。
34. 正态MLE离差平方和为0无域内最大值；最大熵特指微分熵；CLT模型条件不能由因素很多替代。

### 一手资料与证据

1. [UC Davis — John K. Hunter, Power Series, §10.7](https://www.math.ucdavis.edu/~hunter/intro_analysis_pdf/ch10.pdf)：光滑与解析的区别、Taylor不还原反例；§10.2的比值/根值收敛半径条件。
2. [Penn State STAT 414 — Bivariate Normal Distributions](https://online.stat.psu.edu/stat414/Lesson21)：条件均值与条件方差sigma²(1−rho²)。退化边界进一步由该方差为0及协方差行列式为0直接推出。
3. [Calvin Wooyoung Chin, A Short and Elementary Proof of the Central Limit Theorem by Individual Swapping](https://arxiv.org/abs/2106.00871)：提供不需要特征函数知识的CLT证明。
4. [Stanford MS&E 311 Reference Class Notes](https://web.stanford.edu/class/msande311/000311.pdf)：半正定要求全部主子式非负；不能照搬仅顺序主子式规则。
5. [Stanford EE/Stats 376A Homework 7 Solutions, Problem 4](https://web.stanford.edu/~kedart/ee376a_winter1617/hw7sol.pdf)：给定方差的最大微分熵为Gaussian。
6. [Penn State STAT 505 Lesson 1](https://online.stat.psu.edu/stat505/Lesson01)：样本方差n与n−1的口径区别。正态MLE全相同观测的例外独立由似然(2πsigma²)^(−n/2)在sigma²↓0时无界推导，并通过符号极限复核。

### 非模拟题的重点复核

- 二次型考点例：det A=−(a−1)²，任何a都不正定；a=0的谱1,1±sqrt2，所给单位特征向量正交。
- 线代综合ODE：A=[[2,1],[-1,4]]不能对角化，N=A−3I非零但N²=0；e^{At}=e^{3t}(I+tN)，代回导数恒等式为零。
- 旋转ODE：A=[[0,1],[-1,0]]，指数矩阵[[cos t,sin t],[-sin t,cos t]]符号正确。
- 概率考点例cxy在单位方形中c=4，边缘2x、2y，E[XY]=4/9；θx^{θ−1}的矩估计Xbar/(1−Xbar)、MLE=−n/Σln X_i，严格凹验证补齐。
- 两标准正态乘积：均值0、二阶矩1、四阶矩9，排除N(0,1)；补上原文只给结论的理由。
- 一般n个中值点证明：依次使用介值定理可选择递增分点，不需要f单调；中值导数为正非零，取倒数合法。
- 留数例：a>1，单位圆内极点−a+sqrt(a²−1)，留数1/(i sqrt(a²−1))，积分2π/sqrt(a²−1)。
- 数值Newton sqrt2从1迭代4次，误差约1.6×10^-12，原文“10位小数”保守成立。
- Archimedes现代抛物线示例：弓形面积1/6、内接三角形1/8，比值4/3；π分数界与舍入界关系正确。
- 辅助函数反例：f≡1、F=x²，则F'(0)=0但0·f'(0)+2f(0)=2，证实不可约去x因子。
- 共振模板：算子(D−3)²，右端e^{3x}，特解x²e^{3x}/2；根值3与重数2不同，验证修正的必要性。

## 发布后补充：Wiki 中文章节锚点

实际 GitHub Wiki 页面会对自定义中文 `a[name]` 再作百分号编码，与原生 GFM API 的 HTML 片段行为不同。发布后浏览器检查发现，带中文 `#section-…` 的链接停留在页顶，不能仅把它判为验证器误报。
