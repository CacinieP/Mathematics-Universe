# 数理统计基础详解

本文简单随机样本指 $X_1,\ldots,X_n$ 独立同分布。记 $S^2=\frac1{n-1}\sum_i(X_i-\bar X)^2$（$n\geq2$），$S_n^2=\frac1n\sum_i(X_i-\bar X)^2$。正态总体假设为 $N(\mu,\sigma^2)$，$\sigma>0$。

分位数统一采用**上尾约定**：$P(Z>z_\alpha)=\alpha$，$P(T_\nu>t_\alpha(\nu))=\alpha$，$P(V_\nu>\chi^2_\alpha(\nu))=\alpha$。例如 $z_{0.05}=1.645$、$z_{0.025}=1.96$。

## 一、抽样分布

### 1.1 统计量的分布

**样本均值**：$\bar{X} = \frac{1}{n}\sum X_i$

若 $X_i \sim N(\mu,\sigma^2)$：$\bar{X} \sim N(\mu, \sigma^2/n)$

**标准化**：$Z = \frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$

**t统计量**：$T = \frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$（$\sigma$ 未知时用 $S$ 代替）

### 1.2 三大分布的关系

$$Z_1,\ldots,Z_n \text{ 独立且 } Z_i \sim N(0,1) \Rightarrow \sum Z_i^2 \sim \chi^2(n)$$

$$Z \sim N(0,1), V \sim \chi^2(n),\ Z \text{ 与 } V \text{ 相互独立} \Rightarrow Z/\sqrt{V/n} \sim t(n)$$

$$U \sim \chi^2(m), V \sim \chi^2(n),\ U \text{ 与 } V \text{ 独立} \Rightarrow (U/m)/(V/n) \sim F(m,n)$$

$$T \sim t(n) \Rightarrow T^2 \sim F(1,n)$$

> **记忆**：正态→卡方（平方和），正态/卡方→t（除），卡方/卡方→F（比）。

## 二、参数估计

### 2.1 矩估计法

用样本矩代替总体矩。

**步骤**：
1. 用 $k$ 个参数表示前 $k$ 阶矩
2. 令总体矩 = 样本矩
3. 解方程组

**案例**：$X \sim U(a,b)$，矩估计

$E[X] = \frac{a+b}{2}$，$Var(X) = \frac{(b-a)^2}{12}$

$\frac{a+b}{2} = \bar{X}$，$\frac{(b-a)^2}{12} = S_n^2$

$a = \bar{X}-\sqrt{3}S_n$，$b = \bar{X}+\sqrt{3}S_n$

### 2.2 最大似然估计

**步骤**：
1. 写似然函数 $L(\theta) = \prod f(X_i;\theta)$
2. 取对数 $\ell(\theta) = \sum\ln f(X_i;\theta)$
3. 内点候选可通过求导令为 0 得到；支持集依赖参数时，还要检查参数约束和边界
4. 验证是最大值

**案例**：$X \sim P(\lambda)$，MLE

$L(\lambda) = \prod\frac{\lambda^{X_i}e^{-\lambda}}{X_i!}$

$\ell(\lambda) = n\bar{X}\ln\lambda-n\lambda-\sum\ln(X_i!)$

$\frac{d\ell}{d\lambda} = \frac{n\bar{X}}{\lambda}-n = 0$

$\hat{\lambda} = \bar{X}$（这里允许 $\lambda=0$ 的退化 Poisson 分布；若限定 $\lambda>0$ 且样本全为 0，则只有 $\lambda\downarrow0$ 时的上确界，没有域内最大值）

### 2.3 估计量评价

**无偏性**：$E[\hat\theta] = \theta$

**案例**：$S^2 = \frac{1}{n-1}\sum(X_i-\bar{X})^2$ 是 $\sigma^2$ 的无偏估计

证明：$\sum(X_i-\bar{X})^2 = \sum X_i^2-n\bar{X}^2$

$E[\sum X_i^2] = n(\sigma^2+\mu^2)$

$E[n\bar{X}^2] = n(\sigma^2/n+\mu^2) = \sigma^2+n\mu^2$

$E[\sum(X_i-\bar{X})^2] = n\sigma^2+n\mu^2-\sigma^2-n\mu^2 = (n-1)\sigma^2$

$E[S^2] = \sigma^2$ ✓

**为什么除以 $n-1$？** 因为 $\bar{X}$ 已经用掉了一个"自由度"。

## 三、区间估计

### 3.1 正态总体均值

**$\sigma$ 已知**：$\bar{X} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}$

**$\sigma$ 未知**：$\bar{X} \pm t_{\alpha/2}(n-1)\frac{S}{\sqrt{n}}$

### 3.2 正态总体方差

$\left[\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$

上述区间也可用下尾分位数表示，但下标须改为互补概率；参见 [NIST 方差区间说明](https://www.itl.nist.gov/div898/handbook/prc/section2/prc231.htm)。

### 3.3 样本量确定

$E$ 为允许的区间半宽，所需样本量取
$$n\geq\left\lceil\left(\frac{z_{\alpha/2}\sigma}{E}\right)^2\right\rceil.$$

$E$ 是允许误差，$\sigma$ 需要预估。

## 四、假设检验

### 4.1 基本步骤

1. 建立假设 $H_0: \mu = \mu_0$ vs $H_1: \mu \neq \mu_0$
2. 选择统计量 $Z = \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$
3. 给定显著性水平 $\alpha = 0.05$
4. 拒绝域 $|Z| > z_{\alpha/2} = 1.96$
5. 计算并判断

### 4.2 p值

**p值** = 在 $H_0$ 为真的前提下，出现当前或更极端结果的概率。

- $p < \alpha$：拒绝 $H_0$
- $p \geq \alpha$：不拒绝 $H_0$

### 4.3 案例

某品牌电池标称寿命500小时，$\sigma=50$。独立抽测25个，假设寿命服从正态分布，$\bar{X}=488$。能否认为寿命不达标（$\alpha=0.05$）？

$H_0: \mu = 500$ vs $H_1: \mu < 500$

$Z = \frac{488-500}{50/\sqrt{25}} = \frac{-12}{10} = -1.2$

左尾拒绝域为 $Z<-z_{0.05}=-1.645$。

$Z = -1.2 > -1.645$，不拒绝 $H_0$。

在该显著性水平下，证据不足以认定平均寿命低于 500 小时；不拒绝并不等于证明达标。
