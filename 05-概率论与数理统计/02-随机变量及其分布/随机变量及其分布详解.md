# 随机变量及其分布详解

## 一、离散型随机变量

### 1.1 常见分布的联系

**二项分布 $B(n,p)$**：$n$ 次独立Bernoulli试验的成功次数

$P(X=k) = C_n^k p^k(1-p)^{n-k}$

$E[X] = np$，$Var(X) = np(1-p)$

**Poisson分布 $P(\lambda)$**：稀有事件在单位时间/空间内发生的次数

$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$

$E[X] = Var(X) = \lambda$

**Poisson近似**：$B(n,p) \approx P(np)$ 当 $n$ 大 $p$ 小

### 1.2 几何分布与负二项分布

$Geo(p)$：首次成功所需的试验次数

$P(X=k) = p(1-p)^{k-1}$，$k=1,2,\ldots$

$E[X] = 1/p$

**无记忆性**：$P(X>m+n|X>m) = P(X>n)$

## 二、连续型随机变量

### 2.1 均匀分布 $U(a,b)$

$f(x) = \frac{1}{b-a}$，$x \in [a,b]$

$E[X] = \frac{a+b}{2}$，$Var(X) = \frac{(b-a)^2}{12}$

### 2.2 指数分布 $Exp(\lambda)$

$f(x) = \lambda e^{-\lambda x}$，$x \geq 0$

$E[X] = 1/\lambda$，$Var(X) = 1/\lambda^2$

**分布函数**：$F(x) = 1-e^{-\lambda x}$

**应用**：等待时间、元件寿命

### 2.3 正态分布 $N(\mu,\sigma^2)$

**标准化**：$Z = \frac{X-\mu}{\sigma} \sim N(0,1)$

**线性变换**：$aX+b \sim N(a\mu+b, a^2\sigma^2)$

**独立正态变量之和**：$X+Y \sim N(\mu_1+\mu_2, \sigma_1^2+\sigma_2^2)$

**案例**：$X \sim N(3,4)$，求 $P(1 < X < 7)$

$P(1<X<7) = P(\frac{1-3}{2}<Z<\frac{7-3}{2}) = P(-1<Z<2)$

$= \Phi(2)-\Phi(-1) = \Phi(2)-(1-\Phi(1)) = 0.9772-0.1587 = 0.8185$

## 三、随机变量函数的分布

### 3.1 分布函数法

**步骤**：
1. 求 $Y$ 的分布函数 $F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$
2. 通过解不等式 $g(X) \leq y$ 转化为 $X$ 的范围
3. 对 $F_Y$ 求导得密度 $f_Y$

### 3.2 案例：$Y = X^2$ 的分布

$X \sim N(0,1)$，求 $Y = X^2$ 的分布

$F_Y(y) = P(X^2 \leq y) = P(-\sqrt{y} \leq X \leq \sqrt{y}) = 2\Phi(\sqrt{y})-1$

$f_Y(y) = 2\phi(\sqrt{y})\cdot\frac{1}{2\sqrt{y}} = \frac{1}{\sqrt{2\pi y}}e^{-y/2}$

这正是 $\chi^2(1)$ 分布！

> **与统计学的联系**：标准正态变量的平方服从自由度为1的卡方分布。这是三大抽样分布的基础。
