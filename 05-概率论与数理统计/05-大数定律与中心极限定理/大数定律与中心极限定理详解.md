# 大数定律与中心极限定理详解

## 一、大数定律

### 1.1 Chebyshev不等式

$$P(|X-\mu| \geq \varepsilon) \leq \frac{\sigma^2}{\varepsilon^2}$$

**意义**：不需要知道分布，只用期望和方差就能给出概率的界。

**应用**：证明弱大数定律的工具。

### 1.2 弱大数定律（Khinchin）

$X_1,X_2,\ldots$ 独立同分布，$E[X_i]=\mu$：

$$\forall\varepsilon>0: \lim_{n\to\infty}P\left(\left|\frac{1}{n}\sum_{i=1}^n X_i-\mu\right| \geq \varepsilon\right) = 0$$

### 1.3 强大数定律

$$P\left(\lim_{n\to\infty}\frac{1}{n}\sum_{i=1}^n X_i = \mu\right) = 1$$

**区别**：弱大数是"依概率收敛"，强大数是"几乎必然收敛"。

## 二、中心极限定理

### 2.1 Lindeberg-Lévy CLT

$X_1,X_2,\ldots$ 独立同分布，$E[X_i]=\mu$，$Var(X_i)=\sigma^2$：

$$\frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$$

### 2.2 应用案例

**案例1**：掷100次骰子，总点数在330-370之间的概率？

$X_i$ = 第 $i$ 次点数，$E[X_i]=3.5$，$Var(X_i)=35/12$

$S_{100} = \sum X_i$，$E[S]=350$，$Var(S)=3500/12$

$P(330 < S < 370) = P\left(\frac{330-350}{\sqrt{3500/12}} < Z < \frac{370-350}{\sqrt{3500/12}}\right)$

$\approx P(-1.17 < Z < 1.17) \approx 2\Phi(1.17)-1 \approx 0.758$

**案例2**：某系统有100个独立元件，每个正常概率0.9。至少85个正常时系统工作。求系统工作概率。

$X \sim B(100, 0.9)$，$E[X]=90$，$Var(X)=9$

$P(X \geq 85) = P\left(Z \geq \frac{85-90}{3}\right) = P(Z \geq -1.67) = \Phi(1.67) \approx 0.9525$

> **注**：精确二项值为 $0.9601$（此处未修正近似 $0.9525$）；若加上 ±0.5 连续性修正，近似精度更高，修正方法见 2.3 节。

### 2.3 de Moivre-Laplace定理

CLT在二项分布中的特例：$X \sim B(n,p)$

$P(a \leq X \leq b) \approx \Phi\left(\frac{b-np+0.5}{\sqrt{np(1-p)}}\right)-\Phi\left(\frac{a-np-0.5}{\sqrt{np(1-p)}}\right)$

**连续性修正**：±0.5 提高近似精度。

## 三、各种收敛的关系

```
几乎必然收敛 (a.s.)
    ↓ 推出
依概率收敛 (P)
    ↓ 推出
依分布收敛 (d)

反过来不成立，但：
依概率收敛 + 常数极限 ⟺ 依分布收敛到常数
```
