# 大数定律与中心极限定理详解

## 一、大数定律

### 1.1 Chebyshev不等式

设 $E[X]=\mu$、$Var(X)=\sigma^2<\infty$，且 $\varepsilon>0$。

$$P(|X-\mu| \geq \varepsilon) \leq \frac{\sigma^2}{\varepsilon^2}$$

**意义**：不需要知道分布，只用期望和方差就能给出概率的界。

**应用**：证明弱大数定律的工具。

### 1.2 弱大数定律（Khinchin）

$X_1,X_2,\ldots$ 独立同分布，$E[|X_i|]<\infty$，$E[X_i]=\mu$：

$$\forall\varepsilon>0: \lim_{n\to\infty}P\left(\left|\frac{1}{n}\sum_{i=1}^n X_i-\mu\right| \geq \varepsilon\right) = 0$$

### 1.3 强大数定律

在上述独立同分布、绝对可积条件下，还可得到：

$$P\left(\lim_{n\to\infty}\frac{1}{n}\sum_{i=1}^n X_i = \mu\right) = 1$$

**区别**：弱大数是"依概率收敛"，强大数是"几乎必然收敛"。

## 二、中心极限定理

### 2.1 Lindeberg-Lévy CLT

$X_1,X_2,\ldots$ 独立同分布，$E[X_i]=\mu$，$0<Var(X_i)=\sigma^2<\infty$：

$$\frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$$

### 2.2 应用案例

**案例1**：掷100次骰子，总点数在330-370之间的概率？

$X_i$ = 第 $i$ 次点数，$E[X_i]=3.5$，$Var(X_i)=35/12$

$S_{100} = \sum X_i$，$E[S]=350$，$Var(S)=3500/12$

$S$ 为整数，$330<S<370$ 等价于 $331\leq S\leq369$。令 $Z\sim N(0,1)$，连续性修正给出：
$$P(330<S<370)\approx\Phi\left(\frac{369.5-350}{\sqrt{3500/12}}\right)-\Phi\left(\frac{330.5-350}{\sqrt{3500/12}}\right)\approx0.7465.$$
这是正态近似，不是将标准化的离散变量直接等同于标准正态。

**案例2**：某系统有100个独立元件，每个正常概率0.9。至少85个正常时系统工作。求系统工作概率。

$X \sim B(100, 0.9)$，$E[X]=90$，$Var(X)=9$

令 $Z\sim N(0,1)$，采用连续性修正：
$$P(X\geq85)\approx P\left(Z\geq\frac{84.5-90}{3}\right)=\Phi(11/6)\approx0.9666.$$

精确二项值为 $0.9601$。不修正时 $\Phi(5/3)\approx0.9522$；连续性修正通常改善离散边界近似，但不会消除分布偏斜造成的误差。

### 2.3 de Moivre-Laplace定理

CLT在二项分布中的特例：$X \sim B(n,p)$，$0<p<1$，以下 $a,b$ 为整数；近似通常要求 $np$ 与 $n(1-p)$ 都足够大

$P(a \leq X \leq b) \approx \Phi\left(\frac{b-np+0.5}{\sqrt{np(1-p)}}\right)-\Phi\left(\frac{a-np-0.5}{\sqrt{np(1-p)}}\right)$

**连续性修正**：±0.5 提高近似精度。

## 三、各种收敛的关系

```
几乎必然收敛 (a.s.)
    ↓ 推出
依概率收敛 (P)
    ↓ 推出
依分布收敛 (d)

反过来不成立，但：
依概率收敛 + 常数极限 ⟺ 依分布收敛到常数
```
