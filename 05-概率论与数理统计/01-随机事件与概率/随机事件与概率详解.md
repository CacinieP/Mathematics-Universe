# 随机事件与概率详解

## 一、概率公式体系

### 1.1 加法公式

$P(A \cup B) = P(A)+P(B)-P(AB)$

推广：$P(A\cup B\cup C) = P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC)$

### 1.2 条件概率链

$P(AB) = P(A)P(B|A) = P(B)P(A|B)$

$P(ABC) = P(A)P(B|A)P(C|AB)$

### 1.3 全概率与Bayes

**全概率公式**：设 $B_1,\ldots,B_n$ 为完备事件组：
$$P(A) = \sum_{i=1}^n P(A|B_i)P(B_i)$$

**Bayes公式**：
$$P(B_k|A) = \frac{P(A|B_k)P(B_k)}{\sum_i P(A|B_i)P(B_i)}$$

**案例**：三工厂生产同种零件，产量比为1:2:3，次品率分别为0.05, 0.03, 0.01。随机取一件为次品，来自各工厂的概率？

$P(A) = 0.05\times\frac{1}{6}+0.03\times\frac{2}{6}+0.01\times\frac{3}{6} = \frac{0.05+0.06+0.03}{6} = \frac{0.14}{6}$

$P(B_1|A) = \frac{0.05/6}{0.14/6} = \frac{5}{14}$

$P(B_2|A) = \frac{6}{14} = \frac{3}{7}$

$P(B_3|A) = \frac{3}{14}$

## 二、独立性

### 2.1 两两独立 vs 相互独立

**两两独立**：任意两个事件独立，$P(A_iA_j) = P(A_i)P(A_j)$

**相互独立**：任意子集的交等于各事件概率之积

**两两独立 ≠ 相互独立**

**反例**：掷两枚硬币

$A$ = 第一枚正面，$B$ = 第二枚正面，$C$ = 两枚同面

$P(A)=P(B)=P(C)=\frac{1}{2}$

$P(AB)=\frac{1}{4}=P(A)P(B)$ ✓

$P(AC)=\frac{1}{4}=P(A)P(C)$ ✓

$P(BC)=\frac{1}{4}=P(B)P(C)$ ✓

但 $P(ABC)=\frac{1}{4}\neq P(A)P(B)P(C)=\frac{1}{8}$ ✗

所以两两独立但非相互独立。
