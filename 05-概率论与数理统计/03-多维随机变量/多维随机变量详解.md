# 多维随机变量详解

## 一、联合分布

### 1.1 联合分布函数

$F(x,y) = P(X \leq x, Y \leq y)$

**性质**：
- $F(-\infty,y) = F(x,-\infty) = 0$
- $F(+\infty,+\infty) = 1$
- 关于 $x,y$ 分别单调不减，并分别右连续
- 任意矩形的概率非负：$F(b,d)-F(a,d)-F(b,c)+F(a,c)\geq0$（$a<b,c<d$）；仅分别单调还不足以刻画联合分布函数

### 1.2 边缘分布

$F_X(x) = F(x,+\infty)$

$f_X(x) = \int_{-\infty}^{+\infty}f(x,y)dy$

### 1.3 条件分布

$f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)}$（$f_X(x)>0$）

**案例**：$(X,Y)$ 的联合密度 $f(x,y) = \begin{cases}2e^{-(2x+y)}, & x>0,y>0\\0, & \text{else}\end{cases}$

$f_X(x) = \int_0^{+\infty}2e^{-(2x+y)}dy = 2e^{-2x}$（$x > 0$）

$f_Y(y) = \int_0^{+\infty}2e^{-(2x+y)}dx = e^{-y}$（$y > 0$）

$f(x,y) = f_X(x)\cdot f_Y(y)$，所以 $X$ 与 $Y$ **独立**。

## 二、独立性与条件分布

### 2.1 独立判定

$X,Y$ 独立 ⟺ $F(x,y) = F_X(x)F_Y(y)$
⟺ $f(x,y) = f_X(x)f_Y(y)$（有联合密度时，等式几乎处处成立）
⟺ $P(X=x_i,Y=y_j) = P(X=x_i)P(Y=y_j)$（离散）

### 2.2 多维正态分布

$(X,Y) \sim N(\mu_1,\mu_2,\sigma_1^2,\sigma_2^2,\rho)$

**关键性质**：
1. 边缘分布是正态的
2. $X,Y$ 独立 ⟺ $\rho = 0$（联合正态时成立；仅两个边缘各自正态不够）
3. 条件分布 $X|Y=y$ 仍是正态的
4. 任何线性组合 $aX+bY$ 仍是正态的

> **与线性代数的联系**：多维正态的密度函数含二次型 $(\mathbf{x}-\boldsymbol{\mu})^T\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})$，其中 $\Sigma$ 在非退化情形正定；一般协方差矩阵仅正半定。退化多维正态仍可定义，但没有这种关于全空间体积的密度公式。

## 三、随机变量函数的分布

### 3.1 二维函数 $Z = g(X,Y)$

**分布函数法**：$F_Z(z) = P(g(X,Y) \leq z)$

### 3.2 和的分布（卷积公式）

$Z = X+Y$（$X,Y$ 独立）：

$f_Z(z) = \int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)dx$

**案例**：$X,Y \sim Exp(\lambda)$ 独立，$Z = X+Y$

$f_Z(z) = \int_0^z\lambda e^{-\lambda x}\cdot\lambda e^{-\lambda(z-x)}dx = \lambda^2 ze^{-\lambda z}$（$z > 0$）

在 $z\leq0$ 可取密度为 0。这是 $\Gamma(2,\lambda)$ 分布（第二参数采用率参数）！

> **一般规律**：$n$ 个独立 $Exp(\lambda)$ 之和 ∼ $\Gamma(n,\lambda)$（Erlang分布）。
