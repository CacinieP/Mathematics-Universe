# 数字特征详解

## 一、期望的计算技巧

### 1.1 利用期望的线性性

$E[aX+bY] = aE[X]+bE[Y]$（不要求独立！）

**案例**：将 $n$ 封信随机放入 $n$ 个信封，求配对数的期望。

设 $X_i = \begin{cases}1, & \text{第}i\text{封信配对}\\0, & \text{else}\end{cases}$

配对数 $X = X_1+\cdots+X_n$

$E[X_i] = P(X_i=1) = \frac{1}{n}$

$E[X] = \sum E[X_i] = n\cdot\frac{1}{n} = 1$

> **惊人结论**：无论 $n$ 多大，期望配对数永远是1。

### 1.2 全期望公式

$E[X] = E[E[X|Y]]$

**应用**：把复杂期望分解为条件期望的期望。

### 1.3 利用分布的对称性

$X \sim U(-a,a)$：由对称性，$E[X] = 0$，$E[X^3] = 0$

## 二、方差

### 2.1 计算公式

$Var(X) = E[X^2]-(E[X])^2$

### 2.2 独立变量的方差

$Var(aX+bY) = a^2Var(X)+b^2Var(Y)$（要求 $X,Y$ 独立或不相关）

### 2.3 案例

$X \sim B(n,p)$，求 $Var(X)$

$X = X_1+\cdots+X_n$，$X_i$ 独立 $Bernoulli(p)$

$Var(X_i) = E[X_i^2]-(E[X_i])^2 = p - p^2 = p(1-p)$

$Var(X) = np(1-p)$

## 三、协方差与相关系数

### 3.1 协方差计算

$Cov(X,Y) = E[XY]-E[X]E[Y]$

### 3.2 协方差矩阵

$\Sigma = \begin{pmatrix}Var(X)&Cov(X,Y)\\Cov(X,Y)&Var(Y)\end{pmatrix}$

**性质**：实对称正半定

### 3.3 相关系数的意义

$\rho = \frac{Cov(X,Y)}{\sigma_X\sigma_Y}$

- $|\rho| \leq 1$（Cauchy-Schwarz）
- $\rho = \pm 1$ ⟺ $Y = aX+b$（线性关系）
- $\rho = 0$：不相关（但可能存在非线性关系）

**案例**：$X \sim U(-1,1)$，$Y = X^2$

$E[X] = 0$，$E[XY] = E[X^3] = 0$

$Cov(X,Y) = E[XY]-E[X]E[Y] = 0$

$\rho = 0$（不相关），但 $Y$ 完全由 $X$ 决定！非线性关系无法被相关系数捕捉。
