## 三、综合题与跨学科联系

### 3.1 经典综合题类型

**类型一：极限+积分**

例：设 $f$ 连续，求 $\lim_{n\to\infty}\sum_{k=1}^n\frac{n}{n^2+k^2}f\left(\frac{k}{n}\right)$

**分析**：$\frac{n}{n^2+k^2} = \frac{1}{n}\cdot\frac{1}{1+(k/n)^2}$

这是 Riemann和：$\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^n\frac{1}{1+(k/n)^2}f(k/n) = \int_0^1\frac{f(x)}{1+x^2}dx$

**联系**：极限+定积分的定义（高数内部联系）

**类型二：微分方程+级数**

例：验证 $y = \sum_{n=0}^{\infty}\frac{x^n}{(n!)^2}$ 满足微分方程 $xy'' + y' - y = 0$

**方法**：逐项求导（级数的分析性质），代入方程，利用递推关系。

**类型三：线代+微分方程**

例：解方程组 $\frac{dx}{dt} = Ax$，其中 $A = \begin{pmatrix}2&1\\-1&4\end{pmatrix}$

**方法**：特征值分解 $A = P\Lambda P^{-1}$，$e^{At} = Pe^{\Lambda t}P^{-1}$

**类型四：概率+微积分**

例：设 $X \sim f(x)$，求 $Y = X^2$ 的密度函数，再求 $E[Y]$

**方法**：分布函数法求密度，再用积分求期望。

## 四、解题策略

### 4.1 选择题策略

- **排除法**：特殊值代入排除
- **几何直觉**：画图辅助判断
- **反例法**：举反例否定命题
- **对称性**：利用对称简化

### 4.2 证明题策略

| 题型 | 常用方法 |
|------|----------|
| 不等式 | 构造函数+单调性 / 中值定理 / Taylor展开 |
| 存在性 | 中值定理 / 介值定理 / 不动点定理 |
| 唯一性 | 反证法 / 单调性 |
| 恒等式 | 两边求导验证 / 定义出发 |

### 4.3 辅助函数构造（考研难点）

** Rolle定理型**：要证 $\exists\xi$，$f'(\xi) + g(\xi)f(\xi) = 0$

辅助函数：$F(x) = e^{G(x)}f(x)$，其中 $G'(x) = g(x)$

原理：$F' = e^{G(x)}(f' + fG') = e^{G(x)}(f' + fg)$，令 $F' = 0$ 即得 $f'(\xi) = -g(\xi)f(\xi)$，即 $f' + gf = 0$ 在 $\xi$ 处成立

**Lagrange型**：要证 $\exists\xi$，$f'(\xi) = \frac{f(b)-f(a)}{b-a}$

辅助函数：$F(x) = f(x) - \frac{f(b)-f(a)}{b-a}x$

原理：$F(a) = F(b)$，用Rolle定理。

### 4.4 经典难题示例

**题目**：设 $f$ 在 $[0,1]$ 上连续，在 $(0,1)$ 上可导，$f(0)=0$, $f(1)=1$。证明：对任意正整数 $n$，存在 $0 < x_1 < x_2 < \cdots < x_n < 1$，使得 $\sum_{k=1}^n\frac{1}{f'(x_k)} = n$。

**分析**：
- 由介值定理，$\exists c_k$，$f(c_k) = \frac{k}{n}$，$k=0,1,\ldots,n$
- 在 $[c_{k-1}, c_k]$ 上用Lagrange中值定理：$f'(x_k) = \frac{f(c_k)-f(c_{k-1})}{c_k-c_{k-1}} = \frac{1/n}{c_k-c_{k-1}}$
- 所以 $\frac{1}{f'(x_k)} = n(c_k - c_{k-1})$
- $\sum\frac{1}{f'(x_k)} = n\sum(c_k-c_{k-1}) = n(c_n - c_0) = n(1-0) = n$ ✓

**关键洞察**：把"和为n"转化为"区间长度之和=1"，这需要介值定理（分割值域）+ Lagrange中值定理（建立导数与增量的关系）。

## 五、备考时间规划

### 5.1 基础阶段（3-4个月）

- 通读教材，理解概念和定理
- 做基础习题，建立计算能力
- 重点：理解"为什么"，不要只记"怎么做"

### 5.2 强化阶段（2-3个月）

- 按专题训练，总结题型和方法
- 做真题，分析出题规律
- 建立错题本，反复回顾

### 5.3 冲刺阶段（1-2个月）

- 模拟考试，控制时间
- 回顾错题和薄弱环节
- 背诵公式表（最后阶段）
