# 考研综合题与跨学科联系

> 以下是教学综合练习。矩阵指数、复特征向量、PCA 等用于理解联系，不能据此推断为统考必考内容。

## 一、高数+线代综合

### 1.1 二次型+多元极值

**题目**：$f(x,y) = ax^2+2bxy+cy^2$ 正定的充要条件是什么？用此分析 $g(x,y) = e^{f(x,y)}$ 的极值。

$f$ 正定 ⟺ 矩阵 $\begin{pmatrix}a&b\\b&c\end{pmatrix}$ 正定 ⟺ $a > 0$ 且 $ac-b^2 > 0$

$g$ 的驻点：$\nabla g = g\cdot\nabla f = 0$

$\nabla f = (2ax+2by, 2bx+2cy)^T = 0$

在 $a>0$ 且 $ac-b^2>0$ 的正定前提下，系数矩阵可逆，唯一驻点为 $(0,0)$。若不加此前提，驻点不一定唯一。

$g$ 在 $(0,0)$ 的Hessian = $e^{f(0,0)}(H_f + \nabla f \nabla f^T)$

$= e^0(H_f) = H_f$（因为 $\nabla f(0,0) = 0$）

所以 $f$ 正定 ⟹ $H_f$ 正定 ⟹ $g$ 在 $(0,0)$ 取极小值。

### 1.2 矩阵指数+微分方程

**题目**：解方程组 $\mathbf{x}' = A\mathbf{x}$，$A = \begin{pmatrix}0&1\\-1&0\end{pmatrix}$

特征方程：$\lambda^2+1 = 0$，$\lambda = \pm i$

$P = \begin{pmatrix}1&1\\i&-i\end{pmatrix}$，$\Lambda = \begin{pmatrix}i&0\\0&-i\end{pmatrix}$

$e^{At} = Pe^{\Lambda t}P^{-1}$

$= \frac{1}{2}\begin{pmatrix}1&1\\i&-i\end{pmatrix}\begin{pmatrix}e^{it}&0\\0&e^{-it}\end{pmatrix}\begin{pmatrix}1&-i\\1&i\end{pmatrix}$

利用Euler公式 $e^{it} = \cos t+i\sin t$：

$e^{At} = \begin{pmatrix}\cos t&\sin t\\-\sin t&\cos t\end{pmatrix}$

验证：$x_1(t) = c_1\cos t+c_2\sin t$，$x_2(t) = -c_1\sin t+c_2\cos t$

这就是**简谐运动**！

> **联系**：复分析（Euler公式）+ 线性代数（特征值分解）+ 微分方程 = 物理学中的振动理论。

## 二、高数+概率综合

### 2.1 积分+期望

**题目**：设 $X$ 的密度为 $f(x)=cx^2e^{-x}$（$x>0$），其余处为 0，求 $c$ 和 $E[X]$

归一化：$c\int_0^{+\infty}x^2e^{-x}dx = 1$

$\int_0^{+\infty}x^2e^{-x}dx = \Gamma(3) = 2! = 2$

$c = 1/2$

$E[X] = \frac{1}{2}\int_0^{+\infty}x^3e^{-x}dx = \frac{1}{2}\Gamma(4) = \frac{6}{2} = 3$

> 这就是 $\Gamma(3,1)$ 分布（Gamma分布的特例）。

### 2.2 级数+概率

**题目**：$X \sim Geo(p)$，其中 $0<p\leq1$，$X$ 表示首次成功所需的试验次数（取值 $1,2,\ldots$），求 $E[X]$

$E[X] = \sum_{k=1}^{\infty}k\cdot p(1-p)^{k-1} = p\sum_{k=1}^{\infty}kq^{k-1}$（$q=1-p$）

$\sum_{k=1}^{\infty}kq^{k-1} = \frac{d}{dq}\sum_{k=0}^{\infty}q^k = \frac{d}{dq}\frac{1}{1-q} = \frac{1}{(1-q)^2} = \frac{1}{p^2}$

$E[X] = p\cdot\frac{1}{p^2} = \frac{1}{p}$

> **技巧**：逐项求导法求级数和——级数理论在概率论中的直接应用。

## 三、线代+概率综合

### 3.1 协方差矩阵+特征值

**题目**：$(X,Y)$ 服从二维正态分布，$E[X]=E[Y]=0$，$Var(X)=Var(Y)=1$，$\rho=0.5$。求主成分。

$\Sigma = \begin{pmatrix}1&0.5\\0.5&1\end{pmatrix}$

特征方程：$(1-\lambda)^2-0.25 = 0$，$\lambda = 1.5$ 或 $0.5$

$\lambda_1 = 1.5$：$\mathbf{v}_1 = \frac{1}{\sqrt{2}}(1,1)^T$

$\lambda_2 = 0.5$：$\mathbf{v}_2 = \frac{1}{\sqrt{2}}(1,-1)^T$

主成分：$Z_1 = \frac{X+Y}{\sqrt{2}}$（方差1.5），$Z_2 = \frac{X-Y}{\sqrt{2}}$（方差0.5）

**解释**：$X$ 和 $Y$ 正相关（$\rho=0.5$），"和方向"方差大，"差方向"方差小。PCA捕获了这个方向性。

## 四、三科综合

### 4.1 最小二乘法的全景

**问题**：给定数据 $(x_i,y_i)$，$i=1,\ldots,n$，拟合直线 $y = ax+b$

**高数视角**（最优化）：

$\min_{a,b} Q = \sum(y_i-ax_i-b)^2$

$\frac{\partial Q}{\partial a} = 0$，$\frac{\partial Q}{\partial b} = 0$

**线代视角**（投影）：

$X = \begin{pmatrix}x_1&1\\\vdots&\vdots\\x_n&1\end{pmatrix}$，$\mathbf{y} = (y_1,\ldots,y_n)^T$

当 $x_i$ 不全相同时，$X$ 列满秩，$\hat{\boldsymbol{\beta}} = (X^TX)^{-1}X^T\mathbf{y}$；若不满秩，系数解不唯一，可用伪逆给出最小范数解。

系数 $\hat{\boldsymbol{\beta}}$ 的维数是 $2$；真正的**正交投影**是拟合向量 $\hat{\mathbf y}=X\hat{\boldsymbol{\beta}}$，它属于 $X$ 的列空间。

**概率视角**（MLE）：

若设计点 $x_i$ 固定，$\epsilon_i \sim N(0,\sigma^2)$ 独立，且共同方差 $\sigma^2>0$ 已知，则 $Y_i = ax_i+b+\epsilon_i$

似然函数最大 ⟺ $\sum\epsilon_i^2$ 最小 ⟺ 最小二乘

**统一**：三种视角给出同一个结果——最小二乘 = 正交投影 = MLE（正态误差下）。
