# 考研数学模拟题详解——概率论与数理统计

> **说明**：本篇题目为仿考研风格的自编/改编练习题（**非官方真题**）。每题标注考点与难度，编号为「模拟题 N」。

---

**【模拟题 1】**（独立正态变量的线性组合，★★☆）设随机变量 $X \sim N(0,1)$，$Y \sim N(1,4)$，$X,Y$ 独立，则 $P\{X+Y \leq 1\}$ = （ ）

A. $0.3$　　B. $0.5$　　C. $\Phi(1)$　　D. $0.7$

**解析**：

$X+Y \sim N(0+1, 1+4) = N(1, 5)$

$P\{X+Y \leq 1\} = P\left\{\frac{X+Y-1}{\sqrt{5}} \leq 0\right\} = \Phi(0) = 0.5$

**答案**：B

---

**【模拟题 2】**（独立事件的概率计算，★☆☆）设 $X,Y$ 独立同分布，$P\{X=1\}=P\{X=0\}=1/2$，则 $P\{X=Y\}$ = （ ）

A. $1/4$　　B. $1/2$　　C. $3/4$　　D. $1$

**解析**：

$P\{X=Y\} = P\{X=0,Y=0\}+P\{X=1,Y=1\} = (1/2)^2+(1/2)^2 = 1/2$

**答案**：B

---

**【模拟题 3】**（连续随机变量·期望方差，★★★）（11分）设随机变量 $X$ 的概率密度 $f(x) = \begin{cases}cx e^{-x}, & x > 0\\0, & x \leq 0\end{cases}$

（1）求常数 $c$

（2）求 $E[X]$ 和 $Var(X)$

（3）求 $X$ 的分布函数 $F(x)$

**解析**：

**（1）** $\int_0^{+\infty}cx e^{-x}dx = c\Gamma(2) = c\cdot 1 = c = 1$

$c = 1$

> 注：$\int_0^{+\infty}x e^{-x}dx = \Gamma(2) = 1! = 1$

**（2）** $E[X] = \int_0^{+\infty}x\cdot x e^{-x}dx = \Gamma(3) = 2! = 2$

$E[X^2] = \int_0^{+\infty}x^3 e^{-x}dx = \Gamma(4) = 3! = 6$

$Var(X) = 6-4 = 2$

> 这就是 $\Gamma(2,1)$ 分布（Gamma分布），$E[X]=\alpha/\beta = 2$，$Var(X)=\alpha/\beta^2 = 2$

**（3）** $F(x) = \int_0^x t e^{-t}dt = [-te^{-t}]_0^x+\int_0^x e^{-t}dt = -xe^{-x}+1-e^{-x} = 1-(x+1)e^{-x}$（$x > 0$）

**【模拟题 4】**（联合密度的概率计算，★★★）设 $(X,Y)$ 的联合密度 $f(x,y) = \begin{cases}2e^{-(2x+y)}, & x>0,y>0\\0, & \text{else}\end{cases}$，则 $P\{X > Y\}$ = （ ）

A. $1/3$　　B. $1/2$　　C. $2/3$　　D. $3/4$

**解析**：

$P\{X > Y\} = \iint_{x>y>0}2e^{-(2x+y)}dxdy = \int_0^{+\infty}dy\int_y^{+\infty}2e^{-(2x+y)}dx$

$= \int_0^{+\infty}2e^{-y}\cdot\frac{e^{-2y}}{2}dy = \int_0^{+\infty}e^{-3y}dy = \frac{1}{3}$

**答案**：A

**【模拟题 5】**（参数估计全面考察，★★★★）（11分）设总体 $X$ 的密度函数 $f(x) = \begin{cases}\frac{2x}{\theta}e^{-x^2/\theta}, & x > 0\\0, & x \leq 0\end{cases}$（$\theta > 0$），$X_1,\ldots,X_n$ 为样本。

（1）求 $\theta$ 的矩估计 $\hat\theta_1$

（2）求 $\theta$ 的MLE $\hat\theta_2$

（3）判断 $\hat\theta_1$ 和 $\hat\theta_2$ 是否无偏

**解析**：

**（1）矩估计**

先求 $E[X]$。令 $t = x^2$，则 $dt = 2x\,dx$：

$$E[X] = \int_0^{+\infty}x\cdot\frac{2x}{\theta}e^{-x^2/\theta}dx = \int_0^{+\infty}\frac{t^{1/2}}{\theta}e^{-t/\theta}dt = \frac{1}{\theta}\int_0^{+\infty}t^{\frac{3}{2}-1}e^{-t/\theta}dt = \frac{1}{\theta}\cdot\theta^{3/2}\Gamma\left(\frac{3}{2}\right)$$

由 $\Gamma\left(\frac{3}{2}\right) = \frac{1}{2}\Gamma\left(\frac{1}{2}\right) = \frac{\sqrt{\pi}}{2}$，得

$$E[X] = \sqrt{\theta}\cdot\frac{\sqrt{\pi}}{2} = \frac{\sqrt{\pi\theta}}{2}$$

矩估计：$\frac{\sqrt{\pi\hat\theta_1}}{2} = \bar{X}$

$\hat\theta_1 = \frac{4\bar{X}^2}{\pi}$

**（2）MLE**

$L(\theta) = \prod\frac{2X_i}{\theta}e^{-X_i^2/\theta} = \frac{2^n\prod X_i}{\theta^n}e^{-\sum X_i^2/\theta}$

$\ell(\theta) = n\ln 2+\sum\ln X_i-n\ln\theta-\frac{\sum X_i^2}{\theta}$

$\frac{d\ell}{d\theta} = -\frac{n}{\theta}+\frac{\sum X_i^2}{\theta^2} = 0$

$\hat\theta_2 = \frac{\sum X_i^2}{n} = \overline{X^2}$

**（3）无偏性**

$E[X^2] = \int_0^{+\infty}x^2\cdot\frac{2x}{\theta}e^{-x^2/\theta}dx$

令 $t = x^2$：$= \int_0^{+\infty}\frac{t}{\theta}e^{-t/\theta}dt = \theta\Gamma(2)/1 = \theta$

$E[\hat\theta_2] = E[\overline{X^2}] = \theta$ ✓ 无偏

$\hat\theta_1 = 4\bar{X}^2/\pi$，$E[\hat\theta_1] = \frac{4}{\pi}E[\bar{X}^2] = \frac{4}{\pi}(Var(\bar{X})+(E[\bar{X}])^2) \neq \theta$（一般有偏）

**【模拟题 6】**（条件分布·联合密度·边缘密度，★★★）（11分）设 $X \sim U(0,1)$，$Y$ 在给定 $X=x$ 条件下服从 $(x,1)$ 上的均匀分布。

（1）求 $(X,Y)$ 的联合密度

（2）求 $Y$ 的边缘密度

（3）求 $E[Y]$

**解析**：

**（1）** $f_X(x) = 1$（$0 < x < 1$）

$f_{Y|X}(y|x) = \frac{1}{1-x}$（$x < y < 1$）

$f(x,y) = f_X(x)\cdot f_{Y|X}(y|x) = \frac{1}{1-x}$（$0 < x < y < 1$）

**（2）** $f_Y(y) = \int_0^y\frac{1}{1-x}dx = -\ln(1-y)$（$0 < y < 1$）

**（3）** 由（1），$Y|X=x \sim U(x,1)$，故 $E[Y|X=x] = \frac{x+1}{2}$。

由全期望公式：

$$E[Y] = E[E[Y|X]] = E\left[\frac{X+1}{2}\right] = \frac{1}{2}\left(E[X]+1\right) = \frac{1}{2}\left(\frac{1}{2}+1\right) = \frac{3}{4}$$

（用（2）的边缘密度直接验证：$\int_0^1 y\cdot(-\ln(1-y))\,dy = \frac{3}{4}$，结果一致。）

> **评注**：求条件分布结构下的期望时，全期望公式通常比直接用边缘密度积分更高效。

**【模拟题 7】**（区间估计·样本量确定，★★☆）（11分）设 $X_1,\ldots,X_n$ 来自 $N(\mu,\sigma^2)$

（1）求 $\mu$ 的置信水平 $1-\alpha$ 的置信区间（$\sigma$ 已知）

（2）要使置信区间长度不超过 $2d$，至少需要多少样本？

**解析**：

**（1）** $\bar{X} \sim N(\mu, \sigma^2/n)$

$\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$

$P\left(\left|\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}\right| < z_{\alpha/2}\right) = 1-\alpha$

置信区间：$\bar{X} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}$

即 $\left[\bar{X}-z_{\alpha/2}\frac{\sigma}{\sqrt{n}}, \bar{X}+z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right]$

**（2）** 置信区间长度 $L = 2z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \leq 2d$

$z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \leq d$

$n \geq \left(\frac{z_{\alpha/2}\sigma}{d}\right)^2$

**【模拟题 8】**（超几何分布·数字特征·极限分布，★★★）（11分）袋中有 $N$ 个球，其中 $M$ 个红球，$N-M$ 个白球。不放回抽取 $n$ 个，设 $X$ 为红球个数。

（1）求 $X$ 的分布

（2）求 $E[X]$ 和 $Var(X)$

（3）当 $N\to\infty$，$M/N\to p$ 时，$X$ 的极限分布是什么？

**解析**：

**（1）** $X$ 服从超几何分布 $H(n,M,N)$

$P\{X=k\} = \frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}$，$\max(0,n+M-N)\leq k\leq\min(n,M)$

**（2）** $E[X] = n\cdot\frac{M}{N}$

$Var(X) = n\cdot\frac{M}{N}\cdot\frac{N-M}{N}\cdot\frac{N-n}{N-1}$

> **与二项分布的对比**：多了一个修正因子 $\frac{N-n}{N-1}$（有限总体修正）

**（3）** 当 $N\to\infty$，$M/N\to p$：

超几何 → 二项 $B(n,p)$

再由CLT，$n$ 大时 $B(n,p)\to N(np, np(1-p))$

> **直觉**：总体很大时，不放回≈有放回。

**【模拟题 9】**（Bernoulli分布的MLE·估计量评价，★★★）（11分）设总体 $X \sim B(1,p)$（$0 < p < 1$），$X_1,\ldots,X_n$ 为样本。

（1）求 $p$ 的MLE $\hat{p}$

（2）求 $E[\hat{p}]$ 和 $Var(\hat{p})$

（3）证明 $\hat{p}$ 是 $p$ 的一致估计

**解析**：

**（1）** $L(p) = \prod p^{X_i}(1-p)^{1-X_i} = p^{n\bar{X}}(1-p)^{n(1-\bar{X})}$

$\ell(p) = n\bar{X}\ln p+n(1-\bar{X})\ln(1-p)$

$\frac{d\ell}{dp} = \frac{n\bar{X}}{p}-\frac{n(1-\bar{X})}{1-p} = 0$

$\hat{p} = \bar{X}$

**（2）** $E[\hat{p}] = E[\bar{X}] = p$（无偏）

$Var(\hat{p}) = Var(\bar{X}) = \frac{p(1-p)}{n}$

**（3）** 由Chebyshev不等式：

$P(|\hat{p}-p| \geq \varepsilon) \leq \frac{Var(\hat{p})}{\varepsilon^2} = \frac{p(1-p)}{n\varepsilon^2} \leq \frac{1}{4n\varepsilon^2} \to 0$

所以 $\hat{p} \xrightarrow{P} p$，是 $p$ 的一致估计。∎

**【模拟题 10】**（抽样分布·统计量性质，★★☆）设 $X_1,\ldots,X_n$ 来自总体 $N(\mu,\sigma^2)$，$\bar{X}$ 为样本均值，$S^2$ 为样本方差，则下列正确的是（ ）

A. $\bar{X}$ 与 $S^2$ 独立

B. $\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n)$

C. $\frac{\bar{X}-\mu}{S/\sqrt{n}}\sim N(0,1)$

D. $S^2$ 是 $\sigma^2$ 的MLE

**解析**：

A：正态总体下，$\bar{X}$ 与 $S^2$ 独立 ✓（Fisher引理）

B：$\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$，不是 $\chi^2(n)$ ✗

C：应该是 $t(n-1)$，不是 $N(0,1)$ ✗

D：MLE的 $\hat\sigma^2 = \frac{1}{n}\sum(X_i-\bar{X})^2 \neq S^2 = \frac{1}{n-1}\sum(X_i-\bar{X})^2$ ✗

**答案**：A
