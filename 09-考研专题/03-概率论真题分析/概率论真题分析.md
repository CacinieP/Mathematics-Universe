# 概率论真题分析

## 一、选择题高频考点

### 1.1 概率计算

**典型题**：设 $A,B$ 互不相容，$P(A) > 0, P(B) > 0$，则下列正确的是（ ）

A. $P(AB) = 0$
B. $P(A|B) = P(A)$
C. $P(A \cup B) = P(A)+P(B)$
D. $P(\bar{A}\bar{B}) = P(\bar{A})P(\bar{B})$

**分析**：
- A：互不相容 ⟹ $AB=\emptyset$ ⟹ $P(AB)=0$ ✓
- B：$P(A|B) = P(AB)/P(B) = 0 \neq P(A)$（$P(A)>0$）✗
- C：互不相容 ⟹ $P(A\cup B) = P(A)+P(B)$ ✓
- D：$\bar{A}\bar{B}=\overline{A\cup B}$，$P(\overline{A\cup B})=1-P(A)-P(B)$，$P(\bar{A})P(\bar{B})=(1-P(A))(1-P(B))$，一般不等。✗

答案：AC

### 1.2 分布性质

**典型题**：$X,Y$ 独立同分布 $N(0,1)$，则下列不服从正态分布的是（ ）

A. $X+Y$
B. $2X-1$
C. $X^2$
D. $XY$

**分析**：
- A：独立正态之和 ⟹ 正态 ✓
- B：线性变换 ⟹ 正态 ✓
- C：$\chi^2(1)$ ✗
- D：两个独立标准正态之积，不服从正态 ✗

答案：CD

## 二、解答题典型模式

### 2.1 二维随机变量综合题

**典型**：$(X,Y)$ 的联合密度 $f(x,y) = \begin{cases}cxy, & 0<x<1,0<y<1\\0, & \text{else}\end{cases}$

（1）求 $c$

$\int_0^1\int_0^1 cxy\,dxdy = c\cdot\frac{1}{2}\cdot\frac{1}{2} = \frac{c}{4} = 1$，$c=4$

（2）求边缘密度

$f_X(x) = \int_0^1 4xy\,dy = 2x$（$0<x<1$）

$f_Y(y) = \int_0^1 4xy\,dx = 2y$（$0<y<1$）

（3）判断独立性

$f(x,y) = 4xy = 2x\cdot 2y = f_X(x)f_Y(y)$ ✓ 独立

（4）求 $E[XY]$

$E[XY] = \int_0^1\int_0^1 xy\cdot 4xy\,dxdy = 4\int_0^1 x^2 dx\int_0^1 y^2 dy = 4\cdot\frac{1}{3}\cdot\frac{1}{3} = \frac{4}{9}$

或用独立性：$E[XY] = E[X]E[Y] = \frac{2}{3}\cdot\frac{2}{3} = \frac{4}{9}$

### 2.2 参数估计综合题

**典型**：$X_1,\ldots,X_n$ 来自总体 $X$，密度 $f(x) = \begin{cases}\theta x^{\theta-1}, & 0<x<1\\0, & \text{else}\end{cases}$（$\theta > 0$）

（1）矩估计

$E[X] = \int_0^1 x\theta x^{\theta-1}dx = \theta\int_0^1 x^\theta dx = \frac{\theta}{\theta+1}$

$\frac{\theta}{\theta+1} = \bar{X}$，$\theta = \frac{\bar{X}}{1-\bar{X}}$

（2）MLE

$L(\theta) = \theta^n\prod X_i^{\theta-1}$

$\ell(\theta) = n\ln\theta + (\theta-1)\sum\ln X_i$

$\frac{d\ell}{d\theta} = \frac{n}{\theta}+\sum\ln X_i = 0$

$\hat\theta = -\frac{n}{\sum\ln X_i}$

## 三、高频公式速查

| 公式 | 内容 |
|------|------|
| 全概率 | $P(A) = \sum P(A\|B_i)P(B_i)$ |
| 期望线性性 | $E[aX+bY] = aE[X]+bE[Y]$ |
| 方差公式 | $Var(X) = E[X^2]-(E[X])^2$ |
| 协方差 | $Cov(X,Y) = E[XY]-E[X]E[Y]$ |
| 独立方差 | $Var(X+Y) = Var(X)+Var(Y)$ |
| Chebyshev | $P(\|X-\mu\| \geq \varepsilon) \leq \sigma^2/\varepsilon^2$ |
| 样本均值 | $E[\bar{X}]=\mu$，$Var(\bar{X})=\sigma^2/n$ |
| 无偏方差 | $E[S^2]=\sigma^2$（除以 $n-1$）|
