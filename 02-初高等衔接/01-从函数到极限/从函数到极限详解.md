# 从函数到极限——衔接详解

## 一、函数概念的深化

### 1.1 从高中函数到大学函数

高中定义：$f: A \to B$，每个 $x \in A$ 有唯一 $y = f(x) \in B$

大学拓展：
- 定义域不限于实数集，可以是任何集合
- 值域也不限于实数集
- 函数可以是"函数的函数"（算子）
- 函数可以是"集合的子集"（关系视角）

**分类**：

| 类型 | 定义域 | 值域 | 例子 |
|------|--------|------|------|
| 数值函数 | $\mathbb{R}$ | $\mathbb{R}$ | $f(x)=x^2$ |
| 向量函数 | $\mathbb{R}^n$ | $\mathbb{R}$ | $f(\mathbf{x})=\|\mathbf{x}\|^2$ |
| 向量场 | $\mathbb{R}^n$ | $\mathbb{R}^m$ | $\mathbf{f}(\mathbf{x})=A\mathbf{x}$ |
| 泛函 | 函数空间 | $\mathbb{R}$ | $F[f]=\int_0^1f(x)dx$ |
| 算子 | 函数空间 | 函数空间 | $D[f]=f'$ |

### 1.2 初等函数的分类体系

```
初等函数
├── 基本初等函数
│   ├── 幂函数 y = x^α
│   ├── 指数函数 y = a^x
│   ├── 对数函数 y = log_a(x)
│   ├── 三角函数 y = sin x, cos x, tan x, cot x, sec x, csc x
│   ├── 反三角函数 y = arcsin x, arccos x, arctan x
│   └── 常数函数 y = c
└── 由基本初等函数经有限次四则运算和复合得到的函数
```

**非初等函数**（大学引入）：
- $f(x) = |x|$（可用 $\sqrt{x^2}$ 表示，但本质上是分段函数）
- $f(x) = \text{sgn}(x)$（符号函数）
- $f(x) = [x]$（取整函数）
- Dirichlet函数

## 二、极限的严格理论

### 2.1 数列极限

**ε-N定义**：$\lim_{n\to\infty}a_n = a$ 指对 $\forall\varepsilon>0$，$\exists N$，当 $n > N$ 时 $|a_n - a| < \varepsilon$。

**用定义证明极限的步骤**：
1. 给定 $\varepsilon > 0$
2. 要找 $N$，使 $n > N \Rightarrow |a_n - a| < \varepsilon$
3. 解不等式 $|a_n - a| < \varepsilon$ 得到 $n$ 的范围
4. 取 $N$ 为满足条件的最小整数

**案例**：证明 $\lim_{n\to\infty}\frac{2n+1}{3n-1} = \frac{2}{3}$

$$\left|\frac{2n+1}{3n-1}-\frac{2}{3}\right| = \left|\frac{3(2n+1)-2(3n-1)}{3(3n-1)}\right| = \frac{5}{3(3n-1)}$$

当 $n \geq 1$ 时，$3n-1 \geq 2n$，所以 $\frac{5}{3(3n-1)} \leq \frac{5}{6n} < \frac{1}{n}$

取 $N = \lceil\frac{1}{\varepsilon}\rceil$，则 $n > N$ 时 $\frac{1}{n} < \varepsilon$。∎

### 2.2 函数极限

**$\varepsilon-\delta$定义**：$\lim_{x\to x_0}f(x) = L$ 指 $\forall\varepsilon>0$，$\exists\delta>0$，当 $0<|x-x_0|<\delta$ 时 $|f(x)-L|<\varepsilon$。

**关键理解**：
- $0 < |x - x_0|$：$x \neq x_0$（极限不依赖函数在 $x_0$ 处的值）
- 极限存在⟹唯一
- 极限存在的必要条件：左右极限存在且相等

### 2.3 极限的计算方法总结

| 方法 | 适用情形 | 案例 |
|------|----------|------|
| 直接代入 | 连续函数 | $\lim_{x\to 1}(x^2+1) = 2$ |
| 因式分解 | $\frac{0}{0}$ 型 | $\lim_{x\to 1}\frac{x^2-1}{x-1}=2$ |
| 有理化 | 含根号 | $\lim_{x\to 0}\frac{\sqrt{x+1}-1}{x}=\frac{1}{2}$ |
| 夹逼准则 | 不易直接算 | $\lim_{n\to\infty}\frac{\sin n}{n}=0$ |
| 等价无穷小 | 乘除法中的无穷小 | $\lim_{x\to 0}\frac{\sin 2x}{3x}=\frac{2}{3}$ |
| L'Hôpital | $\frac{0}{0}$或$\frac{\infty}{\infty}$ | $\lim_{x\to 0}\frac{e^x-1}{x}=1$ |
| Taylor展开 | 精度要求高 | $\lim_{x\to 0}\frac{e^x-1-x}{x^2}=\frac{1}{2}$ |
| 单调有界 | 递推数列 | $\lim_{n\to\infty}(1+\frac{1}{n})^n=e$ |

### 2.4 等价无穷小替换

当 $x \to 0$：

| 原式 | 等价替换 |
|------|----------|
| $\sin x$ | $x$ |
| $\tan x$ | $x$ |
| $\arcsin x$ | $x$ |
| $\arctan x$ | $x$ |
| $1-\cos x$ | $\frac{x^2}{2}$ |
| $e^x - 1$ | $x$ |
| $\ln(1+x)$ | $x$ |
| $(1+x)^\alpha - 1$ | $\alpha x$ |

**注意**：等价无穷小只能用于**乘除法**中的**因子替换**，不能用于加减法！

**错误示范**：$\lim_{x\to 0}\frac{\tan x - \sin x}{x^3}$

错误：$\frac{x - x}{x^3} = 0$（❌ 加法中不能替换）

正确：$\frac{\sin x(\frac{1}{\cos x}-1)}{x^3} = \frac{\sin x(1-\cos x)}{x^3\cos x} \sim \frac{x \cdot \frac{x^2}{2}}{x^3} = \frac{1}{2}$

### 2.5 两个重要极限

$$\lim_{x\to 0}\frac{\sin x}{x} = 1$$

$$\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x = e$$

**第二重要极限的变体**：
- $\lim_{x\to 0}(1+x)^{1/x} = e$
- $\lim_{n\to\infty}(1+\frac{a}{n})^n = e^a$
- $\lim_{x\to 0}\frac{\ln(1+x)}{x} = 1$
- $\lim_{x\to 0}\frac{e^x-1}{x} = 1$

### 2.6 案例：$\lim_{x\to 0}\frac{(1+x)^{1/x}-e}{x}$

令 $t = (1+x)^{1/x}$，则 $\ln t = \frac{\ln(1+x)}{x}$

$$\lim_{x\to 0}\ln t = \lim_{x\to 0}\frac{\ln(1+x)}{x} = 1$$

所以 $t \to e$。

$$\frac{t - e}{x} = \frac{e(e^{(t-e)/e}-1)}{x}$$

用Taylor展开：$\frac{\ln(1+x)}{x} = 1 - \frac{x}{2} + \frac{x^2}{3} - \cdots$

$t = e^{\ln(1+x)/x} = e^{1-x/2+O(x^2)} = e \cdot e^{-x/2+O(x^2)} = e(1-\frac{x}{2}+O(x^2))$

$\frac{t-e}{x} = \frac{e(1-\frac{x}{2}+O(x^2))-e}{x} = \frac{-ex/2+O(x^2)}{x} = -\frac{e}{2}$

## 三、连续性

### 3.1 连续 vs 不连续

**连续**：$\lim_{x\to x_0}f(x) = f(x_0)$（三要素：极限存在、函数值存在、两者相等）

**间断点分类**：

| 类型 | 条件 | 例子 |
|------|------|------|
| 可去间断 | 左右极限存在且相等，但不等于函数值（或函数值不存在） | $f(x)=\frac{\sin x}{x}$ 在 $x=0$ |
| 跳跃间断 | 左右极限存在但不相等 | $f(x)=[x]$ 在整数点 |
| 无穷间断 | 极限为无穷 | $f(x)=\frac{1}{x}$ 在 $x=0$ |
| 振荡间断 | 极限不存在（非无穷） | $f(x)=\sin\frac{1}{x}$ 在 $x=0$ |

可去和跳跃 = **第一类**（左右极限都存在）
无穷和振荡 = **第二类**（至少一侧极限不存在）

### 3.2 闭区间连续函数的性质

**最值定理**：闭区间上连续函数必有最大值和最小值。

**介值定理**：若 $f$ 在 $[a,b]$ 连续，$f(a) \neq f(b)$，则对 $f(a)$ 和 $f(b)$ 之间的任何值 $c$，存在 $\xi \in (a,b)$ 使 $f(\xi) = c$。

**应用：根的存在性**：若 $f(a)f(b) < 0$，则 $\exists \xi \in (a,b)$，$f(\xi) = 0$。

**案例**：证明 $x^3 - 3x + 1 = 0$ 在 $(0,1)$ 内有根。

$f(0) = 1 > 0$, $f(1) = -1 < 0$，$f$ 连续，由零点定理，$\exists \xi \in (0,1)$ 使 $f(\xi) = 0$。
