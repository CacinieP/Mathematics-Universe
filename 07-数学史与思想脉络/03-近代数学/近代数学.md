# 近代数学——严格化与抽象化的双重革命

> 19 世纪是数学从"计算技巧"转向"严密基础"的世纪。分析的严格化、非欧几何的诞生、群论的创立、复变函数的建立，四条线索共同把数学推向现代形态。

**难度**：[拓展]（了解数学思想演进即可，证明细节超出考研范围）

## 一、时代背景：为什么 19 世纪需要"严格化"

18 世纪 Euler、Lagrange、Laplace 把微积分用到了极致——级数展开、微分方程、天体力学。但他们常常**不顾 rigor**：

- Euler 认为 $\sum_{n=1}^{\infty} (-1)^n = 1/2$（无收敛概念）
- Fourier 宣称任意函数都能展成三角级数（无收敛条件）
- "函数"概念模糊：有时指表达式，有时指曲线

19 世纪的危机来自一个具体问题——**Fourier 级数的收敛性**。要回答"什么样的函数能展成三角级数"，必须重新定义函数、极限、积分。这引爆了整个严格化运动。

## 二、分析的算术化（1817–1872）

### 2.1 Bolzano（1817）——被遗忘的先驱

Bolzano 在《纯粹分析证明》中给出了**第一个严格的介值定理证明**，并提出：

- "连续函数在 $[a,b]$ 上达到上确界"（有界性定理）
- 关键：用 $\varepsilon$-$\delta$ 式思想定义连续（早 Cauchy 4 年）

可惜他的工作埋没近百年，直到 19 世纪末才被重新发现。

### 2.2 Cauchy（1821）——严格化的奠基人

Cauchy 在《分析教程》中给出了影响深远的极限定义：

$$\lim_{x \to a} f(x) = L \iff \forall \varepsilon > 0, \exists \delta > 0, |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon$$

基于此，他重新定义了连续、导数、积分（**Cauchy 积分定义为和的极限**）：

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)(x_i - x_{i-1})$$

**意义**：微积分第一次有了算术化的基础，不再依赖"无穷小量"这种含糊物。

> 📖 Cauchy 中值定理：[[Mathematics-Universe/03-高等数学/02-一元微分学/一元微分学详解.md]]

### 2.3 Weierstrass（1860s）——$\varepsilon$-$\delta$ 的最终形式

Weierstrass 把 Cauchy 的思想推向极致：

- 引入今天通用的 $\varepsilon$-$\delta$ 符号
- 区分**逐点收敛**与**一致收敛**
- 给出处处连续处处不可导的函数（1872）：

$$f(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x), \quad 0 < a < 1, \quad b \text{ 为奇整数}, \quad ab > 1 + \frac{3\pi}{2}$$

**震撼**：直观上"连续曲线就该有切线"的信念彻底破产。函数比想象的病态得多。

### 2.4 Dedekind（1872）——用"分割"定义实数

为了给极限论补上最后一块基石（实数系本身的严密性），Dedekind 提出**分割（cut）**：

一个实数 = 有理数集 $\mathbb{Q}$ 的一个分割 $(A, B)$，其中 $A$ 无最大元、$B = \mathbb{Q} \setminus A$。

**例**：$\sqrt{2}$ 对应分割 $A = \{q \in \mathbb{Q} : q < 0 \text{ 或 } q^2 < 2\}$。

Cantor 同年给出等价的"基本列"定义。**实数系的完备性从此严格化**——这是整个分析的地基。

## 三、非欧几何的革命（1820s–1860s）

### 3.1 两千年的公理之痛

Euclid《几何原本》前 4 条公设简单自明，但**第五公设**（平行公设）显得啰嗦：

> 过直线外一点，有且只有一条直线与已知直线平行。

两千年来，数学家试图用前四条公设证明第五条——全部失败。

### 3.2 三位独立发现者

- **Gauss**（约 1817，未发表）：意识到存在"非欧几何"，怕引起"愚人尖叫"而沉默
- **Lobachevsky**（1829，俄国）：首个公开发表，称为"虚几何"
- **Bolyai**（1832，匈牙利）：独立发现，其父写信给 Gauss，Gauss 回复"我早已想到"令其沮丧

**核心思想**：把第五公设换成它的**否定**——过直线外一点至少有**两条**平行线——推出一整套自洽的几何。

### 3.3 Riemann（1854）——几何的统一视角

Riemann 在就职演讲《论作为几何学基础的假设》中，把几何推广到底流形上：

- 引入**度量张量** $g_{ij}$，定义弧长 $ds^2 = \sum g_{ij}\,dx^i dx^j$
- Euclid 几何、双曲几何、椭圆几何只是度量的三种特例
- 提出"高维弯曲空间"的概念

**历史回响**：60 年后 Einstein 的广义相对论正是建立在 Riemann 几何上。Riemann 提前为物理学准备好了语言。

## 四、代数的解放——群论的诞生

### 4.1 从解方程到对称性

19 世纪初，最后的代数问题是：**五次方程有没有求根公式？**

- Abel（1824）证明：一般五次方程**没有**根式解
- **Galois（1832）**给出更深层的回答：方程可解 $\iff$ 其 Galois 群可解

Galois 把"方程能不能解"转化为"群的结构"问题——这是数学思想的一次范式跃迁。他 21 岁死于决斗，手稿在死后 14 年才被 Liouville 发表。

### 4.2 群的公理化

Cayley（1854）给出抽象群的定义：

一个群 $(G, \cdot)$ 满足：封闭性、结合律、单位元、逆元。

**意义**：代数不再研究"具体的数和运算"，而研究"满足公理的抽象结构"。这是从**实体**到**关系**的思维转变。

## 五、复变函数论的建立

### 5.1 Cauchy 的复积分（1825）

Cauchy 定义了复平面的积分，并发现：

$$\oint_\gamma f(z)\,dz = 0 \quad (\text{若 } f \text{ 在 } \gamma \text{ 内解析})$$

这是著名的 **Cauchy 积分定理**。由此推出 Cauchy 积分公式：

$$f(z_0) = \frac{1}{2\pi i} \oint_\gamma \frac{f(z)}{z - z_0}\,dz$$

**惊人推论**：解析函数**无穷次可导**——一次可导则处处光滑。这是复分析与实分析的鸿沟。

### 5.2 Riemann 与 Weierstrass 的两条路线

- **Riemann 路线**：几何直观，用保形映射、Riemann 面
- **Weierstrass 路线**：幂级数展开，纯分析严格化

两派一度对立，最终融合成现代复变函数论。

## 六、19 世纪数学的精神遗产

| 传统数学 | 近代数学（19 世纪转折后） |
|---------|------------------------|
| 计算技巧 | 严格证明 |
| 具体对象（数、函数） | 抽象结构（群、空间、流形） |
| 单一 Euclid 几何 | 多种几何并存 |
| 依赖直觉 | $\varepsilon$-$\delta$ 形式化 |
| 解方程 | 研究对称性 |

**一句话**：19 世纪让数学从"算"变成"证"，从"实体"变成"结构"。现代数学的所有特征——公理化、抽象化、结构化——都在这个世纪定型。
