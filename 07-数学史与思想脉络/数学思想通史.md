# 数学思想通史——从泥板到计算机

> 数学的历史不是定理的编年史，而是人类思维方式的演化史。

## 第一纪：经验数学（公元前3000年 - 前600年）

### 古埃及与巴比伦

**埃及（约公元前1650年，Rhind纸草书）**：
- 能解简单线性方程
- 圆面积近似：$A = (\frac{8}{9}d)^2$（相当于 $\pi \approx 3.16$）
- 建立了单位分数展开系统

**巴比伦（约公元前1800年，Plimpton 322泥板）**：
- 60进制（今天的时间、角度由此而来）
- 能解二次方程
- 知道勾股数（如3-4-5, 5-12-13）
- 使用了位置记数法

**史料特点**：留存材料主要展示算法、例题和实际问题，不能仅凭这些材料断言古代作者完全没有论证意识。

## 第二纪：公理数学（公元前600年 - 公元300年）

### 希腊革命

**Thales（约624-546 BC）**：后世传统将若干几何论证归于他，但著作未存，不能确认“首次”
**Pythagoras（约570-495 BC）**："万物皆数"
**Euclid（约300 BC）**：《几何原本》

**Euclid的伟大贡献**：
1. 以公设、共同概念和定义组织大量几何与数论命题；部分证明仍含未明说的假设
2. 建立了**公理化方法**——数学的核心方法论
3. 这种"从基本假设出发推导一切"的方法影响了西方思想2000年

**无理数的发现（约公元前500年）**：
- Pythagoras学派发现 $\sqrt{2}$ 不是有理数
- 这引发了"第一次数学危机"：几何量不能全部用整数比表示
- 结果：代数几何化（用几何量代替数来处理运算）

### Apollonius与Archimedes

**Apollonius（约262-190 BC）**：圆锥曲线论
- 用纯几何方法系统研究了椭圆、抛物线、双曲线的许多重要性质
- 1800年后Kepler发现行星轨道是椭圆——数学走到了物理前面

**Archimedes（约287-212 BC）**：穷竭法
- 用多边形逼近圆 → $\pi$ 的精确估计
- 这是**积分思想的雏形**
- 计算了抛物线弓形的面积（现代可用定积分验证，例如 $y=x$ 与 $y=x^2$ 之间弓形的面积为 $\int_0^1(x-x^2)\,dx=1/6$）

## 第三纪：代数革命（公元300年 - 1600年）

### 印度与阿拉伯

**印度数学（4-12世纪）**：
- Brahmagupta（598-668）：阐述零与负数的运算法则；零的符号及位值记数法经过更长的演变
- 数码系统（0-9）传到阿拉伯 → "阿拉伯数字"

**Al-Khwarizmi（约780-850）**：
- 《代数学》（Al-jabr）→ "代数"一词的来源
- 系统化了一元二次方程的解法

### 文艺复兴代数

**三次方程（16世纪意大利）**：
- del Ferro / Tartaglia / Cardano：$x^3 + px = q$ 的解法
- Bombelli（1526-1572）：在解三次方程时遇到复数，接受并运算
- 这导致复数的引入——纯代数需求催生了新的数系

**Viète（1540-1603）**：
- 用字母表示未知量和系数
- 代数从"解具体方程"变为"研究方程的一般性质"

## 第四纪：微积分时代（1600年 - 1800年）

### 前奏：解析几何

**Descartes（1596-1650）**：La Géométrie (1637)
- 坐标系：几何问题 → 代数问题
- 曲线的代数表示：$y = f(x)$
- 这是**代数与几何的统一**

### Newton与Leibniz

**Newton（1643-1727）**：
- 从物理问题出发（运动学）
- "流数术"：变量随时间变化的速率
- 《自然哲学的数学原理》(1687)

**Leibniz（1646-1716）**：
- 从几何问题出发（切线、面积）
- 符号系统 $\frac{dy}{dx}$, $\int$ ——沿用至今
- 强调微分是无穷小量之比

**两人的共同贡献**：
- 发现微分和积分互为逆运算（Newton-Leibniz公式）
- 把前人分散的结果统一为一般方法
- 创造了处理"变化"和"累积"的通用工具

### Euler时代

**Euler（1707-1783）**——极为多产的数学家：
- $e^{i\pi} + 1 = 0$（最美的公式）
- 将函数概念一般化
- 建立了分析学的标准形式
- 对数论、图论、变分法等都有开创性贡献

## 第五纪：严格化与抽象化（1800年 - 1900年）

### 分析严格化

**Cauchy（1789-1857）**：
- 以极限和无穷小推进连续、导数等概念的严格化；现代量词化的 ε–δ 表述经后续发展形成
- 《分析教程》(1821)：分析严格化的重要里程碑，此后仍需澄清一致收敛、实数构造等问题

**Weierstrass（1815-1897）**：
- 处处连续但处处不可导的函数（颠覆直觉！）
- 一致收敛理论
- 推动分析算术化；实数的严格构造由 Dedekind、Cantor、Weierstrass 等多条路线发展

**Dedekind（1831-1916）**：
- Dedekind分割：用有理数的分割定义实数
- 实数完备性的严格表达

### 代数抽象化

**Galois（1811-1832）**：
- 群论的奠基者之一
- 建立方程根式可解性与群结构的联系；一般五次方程不存在通用根式公式的证明归功于 Abel（1824）
- 引入了"群"的概念——对称性的代数描述
- 20岁死于决斗，但他的理论改变了代数学

**从具体到抽象的链条**：
```
解方程 → 置换群 → 群论 → 抽象代数
         ↓
      对称性的研究
         ↓
    晶体学、粒子物理（规范群）
```

### 非欧几何

**Gauss / Bolyai / Lobachevsky（约1830年）**：
- 发展与平行公设不同的双曲几何；其相对一致性和独立性后来通过模型进一步确立
- 存在"弯曲的"几何
- **影响**：空间不一定是"平"的 → Einstein广义相对论

### Cantor与集合论

**Cantor（1845-1918）**：
- 无穷有不同的"大小"（$\aleph_0 < 2^{\aleph_0} = |\mathbb{R}|$，Cantor；$2^{\aleph_0}$ 是否等于 $\aleph_1$ 即连续统假设）
- 对角线论证法
- 集合论的发展引出基础问题；Russell 悖论针对无限制概括原则，并不说明 Cantor 关于不同无穷的定理有误

## 第六纪：现代数学（1900年至今）

### Hilbert纲领

**Hilbert（1862-1943）**：
- 希望将全部数学公理化并证明其一致性
- 1900年提出23个问题，指引了20世纪数学的方向

### Gödel不完备定理（1931）

**Gödel（1906-1978）**：
- 任何一致、可有效公理化、足以表达基本算术的系统，都有在该系统中既不可证也不可否证的句子（采用 Gödel–Rosser 版本）
- **含义**：这样的单一系统不能判定全部算术句子；这不等于数学不能形式化
- 对 Hilbert 原始纲领提出根本限制，但形式化和证明论仍继续发展

### 计算机与计算数学

**Turing（1912-1954）**：
- Turing机：计算的数学模型
- 可计算性的严格定义
- 停机问题的不可判定性

**Von Neumann（1903-1957）**：
- 博弈论
- 数值分析
- 计算机体系结构

### 20世纪的大一统

| 统一 | 内容 | 数学分支 |
|------|------|----------|
| Langlands纲领 | 数论与表示论的对应 | 代数数论·表示论 |
| Grothendieck革命 | 代数几何的概形（scheme）理论重建 | 代数几何·交换代数 |
| Atiyah-Singer指标定理 | 分析与拓扑的统一 | 微分算子·拓扑 |
| Poincaré猜想（Perelman，2002–2003 年预印本） | 闭、单连通三维流形同胚于三维球面；是三维拓扑的重要特例 | 微分几何·拓扑 |

## 数学史的启示

### 六次重大跨越

1. **经验→公理**（希腊）：引入证明
2. **修辞→符号**（阿拉伯-欧洲）：引入符号表示
3. **静态→动态**（Newton-Leibniz）：引入变化率
4. **直观→严格**（Cauchy-Weierstrass）：ε-δ语言
5. **具体→抽象**（Galois-Cantor）：群、集合
6. **确定→计算**（Turing）：可计算性

### 每次跨越的共同模式

```
直觉发现 → 大胆使用 → 发现矛盾/不严格 → 严格化/公理化 → 新的抽象层次
```

- 负数：先有人用 → 被质疑 → 严格化（数系扩充）
- 微积分：Newton/Leibniz大胆用 → Berkeley批评 → Cauchy严格化
- 复数：Cardano用 → 被质疑 → Gauss严格化
- 无穷集合：Cantor用 → Russell悖论 → ZFC公理化
