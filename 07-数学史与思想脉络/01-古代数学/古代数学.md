# 古代数学——从计数到证明

## 一、数学的起源

### 1.1 计数的诞生（约公元前35000年）

最早的数学活动是计数。Lebombo骨（约公元前35000年）刻有29个刻痕，可能是月相记录。

### 1.2 两个源头

**埃及数学**：
- Rhind纸草书（约公元前1650年）
- 侧重实用：面积、体积、简单方程
- $\pi$ 的近似值 $\approx 3.16$
- 分数运算系统（单位分数）

**巴比伦数学**：
- 60进制（今天时间和角度的遗产）
- Plimpton 322泥板（约公元前1800年）：大量勾股数
- 能解二次方程
- 位置记数法的先驱

**对比**：
| 特征 | 埃及 | 巴比伦 |
|------|------|--------|
| 进制 | 10进制 | 60进制 |
| 分数 | 单位分数 | 60进制小数 |
| 代数 | 简单方程 | 二次方程 |
| 几何 | 经验公式 | 勾股数表 |
| 特点 | 实用 | 抽象倾向 |

## 二、希腊革命——从算法到证明

### 2.1 Thales（约624-546 BC）

**贡献**：首次引入演绎证明
- 圆的直径平分圆
- 等腰三角形底角相等
- 对顶角相等

**意义**：数学从"怎么算"变为"为什么"。

### 2.2 Pythagoras学派（约530 BC）

**核心信条**："万物皆数"（整数比解释一切）

**危机**：$\sqrt{2}$ 的不可公度性

**证明**（反证法）：假设 $\sqrt{2} = p/q$（既约分数）

$2 = p^2/q^2$，$p^2 = 2q^2$

$p^2$ 是偶数，所以 $p$ 是偶数，$p = 2m$

$4m^2 = 2q^2$，$q^2 = 2m^2$

$q^2$ 是偶数，所以 $q$ 是偶数

$p,q$ 都是偶数，与"既约"矛盾。∎

**影响**：
1. 不可公度量的存在 ⟹ 几何量不能用整数比完全表示
2. 促使希腊人转向几何方法（几何代数）
3. "第一次数学危机"

### 2.3 Euclid（约300 BC）

《几何原本》：
- 13卷，465个命题
- 从5条公设+5条公理出发
- 演绎出整个平面几何和数论

**5条公设**（前三条直观，第四条简单，第五条复杂）：
1. 两点确定一条直线
2. 直线段可以无限延长
3. 以任意中心和半径可以画圆
4. 所有直角相等
5. **平行公设**（等价于：过直线外一点，有且仅有一条平行线）

第五公设的独立性 → 19世纪非欧几何 → Einstein广义相对论

**Euclid算法**（辗转相除法）：求最大公约数

$\gcd(a,b) = \gcd(b, a \mod b)$

至今仍是数论和密码学（RSA）的基础算法。

### 2.4 Archimedes（约287-212 BC）

**数学成就**：
- 穷竭法：用多边形逼近圆 → $\pi$ 的估计
  - 内接96边形：$3.1408 < \pi < 3.1429$
- 抛物线弓形面积 = $\frac{4}{3}\Delta$（外切三角形面积的4/3）
  - 等价于 $\int_0^1 x^2 dx = 1/3$
- 螺线 $r = a\theta$ 的性质
- 球体积 = $\frac{4}{3}\pi r^3$（用力学方法发现，用穷竭法证明）

**方法论意义**：Archimedes先用物理直觉（杠杆原理）发现结果，再用严格的数学方法证明。这种方法论至今适用。
