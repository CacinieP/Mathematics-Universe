# 特征值与特征向量详解

## 一、计算方法

### 1.1 步骤

1. 写出特征方程 $|\lambda I - A| = 0$
2. 解出特征值 $\lambda_1, \lambda_2, \ldots, \lambda_n$
3. 对每个 $\lambda_i$，解 $(\lambda_i I - A)\mathbf{x} = 0$
4. 基础解系给出对应特征空间的一组基；该空间中所有非零向量才是对应的特征向量

### 1.2 案例

$A = \begin{pmatrix}3&2\\-1&0\end{pmatrix}$

特征方程：$|\lambda I-A| = \begin{vmatrix}\lambda-3&-2\\1&\lambda\end{vmatrix} = \lambda^2-3\lambda+2 = 0$

$\lambda_1 = 1$，$\lambda_2 = 2$

$\lambda_1 = 1$：$(I-A)\mathbf{x} = \begin{pmatrix}-2&-2\\1&1\end{pmatrix}\mathbf{x} = 0$

$\mathbf{x} = k\begin{pmatrix}1\\-1\end{pmatrix}$（作为特征向量时 $k\neq0$）

$\lambda_2 = 2$：$(2I-A)\mathbf{x} = \begin{pmatrix}-1&-2\\1&2\end{pmatrix}\mathbf{x} = 0$

$\mathbf{x} = k\begin{pmatrix}2\\-1\end{pmatrix}$（作为特征向量时 $k\neq0$）

## 二、对角化

### 2.1 可对角化的判定

**定理**：$A$ 可对角化 ⟺ $A$ 有 $n$ 个线性无关的特征向量

**等价条件**（特征多项式须在所讨论的数域内完全分裂；在 $\mathbb C$ 上自动满足，在 $\mathbb R$ 上要求全部特征值为实数）：
- 每个 $k_i$ 重特征值有 $k_i$ 个线性无关的特征向量
- $r(\lambda_i I - A) = n - k_i$ 对所有 $i$

**不同特征值 ⟹ 特征向量线性无关**

### 2.2 对角化的应用

**应用一：矩阵幂**

$A = P\Lambda P^{-1}$ ⟹ $A^k = P\Lambda^k P^{-1}$

**应用二：矩阵函数**

$e^{At} = P e^{\Lambda t} P^{-1}$（微分方程）

$f(A) = P f(\Lambda) P^{-1}$

### 2.3 案例：利用对角化求 $A^n$

$A = \begin{pmatrix}1&1\\0&2\end{pmatrix}$

特征值：$\lambda_1 = 1$，$\lambda_2 = 2$

$\lambda_1 = 1$：$\mathbf{v}_1 = \begin{pmatrix}1\\0\end{pmatrix}$

$\lambda_2 = 2$：$\mathbf{v}_2 = \begin{pmatrix}1\\1\end{pmatrix}$

$P = \begin{pmatrix}1&1\\0&1\end{pmatrix}$，$\Lambda = \begin{pmatrix}1&0\\0&2\end{pmatrix}$

$A^n = P\Lambda^n P^{-1} = \begin{pmatrix}1&1\\0&1\end{pmatrix}\begin{pmatrix}1&0\\0&2^n\end{pmatrix}\begin{pmatrix}1&-1\\0&1\end{pmatrix}$

$= \begin{pmatrix}1&2^n-1\\0&2^n\end{pmatrix}$

验证 $n=1$：$\begin{pmatrix}1&1\\0&2\end{pmatrix}$ ✓

## 三、实对称矩阵

### 3.1 核心性质

1. 特征值全为实数
2. 不同特征值的特征向量正交
3. 一定可以正交对角化：$A = Q\Lambda Q^T$

### 3.2 正交对角化步骤

1. 求特征值和特征向量
2. 对同一特征值的多个特征向量，用Schmidt正交化
3. 将所有特征向量单位化
4. 排成正交矩阵 $Q$

### 3.3 案例

$A = \begin{pmatrix}2&-1\\-1&2\end{pmatrix}$

$|\lambda I-A| = (\lambda-2)^2-1 = \lambda^2-4\lambda+3 = 0$

$\lambda_1 = 1$：$\mathbf{v}_1 = \begin{pmatrix}1\\1\end{pmatrix}$，单位化 $\mathbf{q}_1 = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix}$

$\lambda_2 = 3$：$\mathbf{v}_2 = \begin{pmatrix}1\\-1\end{pmatrix}$，单位化 $\mathbf{q}_2 = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\-1\end{pmatrix}$

$Q = \frac{1}{\sqrt{2}}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$

$A = Q\begin{pmatrix}1&0\\0&3\end{pmatrix}Q^T$

> **工程应用**：这就是**振动模态分析**。当质量矩阵为单位矩阵时，$A$ 代表刚度矩阵，特征值是固有角频率的平方，特征向量是振型；一般应解 $K\mathbf v=\omega^2M\mathbf v$。

## 四、正定矩阵

### 4.1 等价条件

设 $A$ 为实对称矩阵。$A$ 正定 ⟺ 以下任一条件成立：
1. $\forall \mathbf{x}\neq 0$，$\mathbf{x}^TA\mathbf{x} > 0$
2. 所有特征值 $> 0$
3. 所有顺序主子式 $> 0$
4. $A = C^TC$（$C$ 可逆）
5. 存在正交矩阵 $Q$ 使 $A = Q\text{diag}(\lambda_i)Q^T$，$\lambda_i > 0$

### 4.2 正定的应用

- **多元极值**：二次连续可微函数在驻点的 Hessian 正定 ⟹ 该点是严格局部极小值点
- **优化**：在开凸域上，二次可微函数凸 ⟺ Hessian 处处正半定；处处正定是严格凸的充分条件，非必要条件（如 $x^4$）
  参见 [Boyd 与 Vandenberghe《Convex Optimization》§3.1.4](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf)。
- **概率论**：协方差矩阵正半定
- **数值分析**：正定矩阵可用Cholesky分解
