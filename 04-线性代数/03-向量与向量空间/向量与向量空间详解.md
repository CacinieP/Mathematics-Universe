# 向量与向量空间详解

## 一、线性相关与无关

### 1.1 判定方法

**方法一（定义法）**：$\sum k_i\boldsymbol{\alpha}_i = 0$，若只有 $k_i=0$ 的解则无关。

**方法二（矩阵法）**：$\boldsymbol{\alpha}_1,\ldots,\boldsymbol{\alpha}_m$ 线性相关 ⟺ $r(A) < m$（$A$ 是以这些向量为列的矩阵）

**方法三（行列式法）**：$n$ 个 $n$ 维向量线性相关 ⟺ $|A| = 0$

### 1.2 重要定理

1. $m$ 个 $n$ 维向量（$m > n$）必线性相关
2. 部分组线性相关 ⟹ 整体组线性相关
3. 整体组线性无关 ⟹ 部分组线性无关
4. $\boldsymbol{\alpha}_1,\ldots,\boldsymbol{\alpha}_m$ 线性无关，加入 $\boldsymbol{\beta}$ 后线性相关 ⟹ $\boldsymbol{\beta}$ 可由 $\boldsymbol{\alpha}_i$ 唯一表示

### 1.3 极大无关组

**求法**：将向量组排成矩阵，做行变换化为阶梯形，主元所在列对应的原向量就是极大无关组。

## 二、基变换与坐标变换

### 2.1 过渡矩阵

从基 $\{\mathbf{e}_1,\ldots,\mathbf{e}_n\}$ 到基 $\{\mathbf{f}_1,\ldots,\mathbf{f}_n\}$：

$(\mathbf{f}_1,\ldots,\mathbf{f}_n) = (\mathbf{e}_1,\ldots,\mathbf{e}_n)P$

$P$ 就是过渡矩阵。

### 2.2 坐标变换

$\mathbf{x} = P\mathbf{y}$（$\mathbf{x}$ 是旧坐标，$\mathbf{y}$ 是新坐标）

> **与Fourier分析的联系**：坐标变换 = 基变换。Fourier变换本质上就是从时域基到频域基的坐标变换。

## 三、Schmidt正交化

**步骤**：

$\mathbf{v}_1 = \mathbf{u}_1$

$\mathbf{v}_2 = \mathbf{u}_2 - \frac{\langle\mathbf{u}_2,\mathbf{v}_1\rangle}{\langle\mathbf{v}_1,\mathbf{v}_1\rangle}\mathbf{v}_1$

$\mathbf{v}_3 = \mathbf{u}_3 - \frac{\langle\mathbf{u}_3,\mathbf{v}_1\rangle}{\langle\mathbf{v}_1,\mathbf{v}_1\rangle}\mathbf{v}_1 - \frac{\langle\mathbf{u}_3,\mathbf{v}_2\rangle}{\langle\mathbf{v}_2,\mathbf{v}_2\rangle}\mathbf{v}_2$

**案例**：将 $\mathbf{u}_1=(1,1,0)$, $\mathbf{u}_2=(1,0,1)$, $\mathbf{u}_3=(0,1,1)$ 正交化

$\mathbf{v}_1 = (1,1,0)$

$\mathbf{v}_2 = (1,0,1)-\frac{1}{2}(1,1,0) = (\frac{1}{2},-\frac{1}{2},1)$

$\mathbf{v}_3 = (0,1,1)-\frac{\langle(0,1,1),\mathbf{v}_1\rangle}{\langle\mathbf{v}_1,\mathbf{v}_1\rangle}\mathbf{v}_1-\frac{\langle(0,1,1),\mathbf{v}_2\rangle}{\langle\mathbf{v}_2,\mathbf{v}_2\rangle}\mathbf{v}_2$

其中 $\langle(0,1,1),\mathbf{v}_1\rangle = 1$（注意：不是 0），$\langle\mathbf{v}_1,\mathbf{v}_1\rangle = 2$；$\langle(0,1,1),\mathbf{v}_2\rangle = \frac{1}{2}$，$\langle\mathbf{v}_2,\mathbf{v}_2\rangle = \frac{3}{2}$。故

$\mathbf{v}_3 = (0,1,1)-\frac{1}{2}(1,1,0)-\frac{1}{3}(\frac{1}{2},-\frac{1}{2},1)$

$= (-\frac{2}{3},\frac{2}{3},\frac{2}{3})$

**正交性验证**：$\langle\mathbf{v}_3,\mathbf{v}_1\rangle = -\frac{2}{3}+\frac{2}{3}+0 = 0$；$\langle\mathbf{v}_3,\mathbf{v}_2\rangle = -\frac{1}{3}-\frac{1}{3}+\frac{2}{3} = 0$ ✓

单位化后就是标准正交基。
