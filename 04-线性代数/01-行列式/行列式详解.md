# 行列式详解

## 一、行列式的计算技巧

### 1.1 化三角形法

通过行变换将行列式化为上三角。

**步骤**：
1. 利用第1行消去下面各行的第1列元素
2. 利用第2行消去下面各行的第2列元素
3. 以此类推
4. 若只做倍加变换，对角线乘积即为原行列式值；交换两行要变号，某行乘 $k\neq0$ 要记录并除去该因子。主元为零时需换行或判定剩余列全为零。

### 1.2 递推法

**案例**：
$$D_n = \begin{vmatrix}2&1&0&\cdots&0\\1&2&1&\cdots&0\\0&1&2&\cdots&0\\\vdots&&&\ddots&1\\0&0&0&1&2\end{vmatrix}$$

按第一行展开：$D_n = 2D_{n-1}-D_{n-2}$

特征方程：$r^2-2r+1=0$，$r=1$（重根）

$D_n = (C_1+C_2 n)\cdot 1^n = C_1+C_2 n$

$D_1=2$，$D_2=3$：$C_1+C_2=2$，$C_1+2C_2=3$

$C_2=1$，$C_1=1$，$D_n = n+1$

### 1.3 升阶法（加边法）

对某些低维规律不明显的行列式，可以加一行一列使其更容易处理。

### 1.4 利用性质的巧算

**案例**：
$$D = \begin{vmatrix}a&b&c&d\\a&b&d&c\\a&c&b&d\\a&c&d&b\end{vmatrix}$$

**教学点：行差成比例 ⟹ 行线性相关 ⟹ D=0**（这类行列式不必硬展开求值）

对第 2、4 行作行差（行变换不改变行列式的值）：

- $r_2 - r_1 = (0,0,d-c,c-d) = (d-c)(0,0,1,-1)$
- $r_4 - r_3 = (0,0,d-b,b-d) = (d-b)(0,0,1,-1)$

$$D \xrightarrow{\;r_2-r_1,\; r_4-r_3\;} \begin{vmatrix}a&b&c&d\\0&0&d-c&c-d\\a&c&b&d\\0&0&d-b&b-d\end{vmatrix}$$

变换后的第 2、4 行都是 $(0,0,1,-1)$ 的倍数，两行成比例 ⟹ 四个行向量线性相关 ⟹ $D = 0$。

（若 $d=c$ 或 $d=b$，则对应行直接变为零行，仍有两行成比例，结论不变。数值抽查：取 $a=1,b=2,c=3,d=4$ 或随机取参数直接计算四阶行列式，恒得 $D=0$。）

### 1.5 范德蒙德行列式的应用

$$V_n = \prod_{1\leq i<j\leq n}(x_j-x_i)$$

**案例**：证明 $D_n = \begin{vmatrix}1&1&1&1\\x_1&x_2&x_3&x_4\\x_1^2&x_2^2&x_3^2&x_4^2\\x_1^3&x_2^3&x_3^3&x_4^3\end{vmatrix} = \prod_{1\leq i<j\leq 4}(x_j-x_i)$

这就是4阶Vandermonde行列式。

## 二、行列式的重要定理

### 2.1 展开定理

$$D = \sum_{j=1}^n a_{ij}A_{ij} = \sum_{j=1}^n a_{ij}(-1)^{i+j}M_{ij}$$

**推论**（异行代数余子式之和为零）：
$$\sum_{j=1}^n a_{ij}A_{kj} = 0 \quad (i \neq k)$$

**应用**：已知行列式某行的代数余子式，构造新行列式求值。

### 2.2 Cramer法则

$n$ 元线性方程组 $Ax = b$，若 $|A| \neq 0$：
$$x_j = \frac{D_j}{D}$$

其中 $D_j$ 是把 $A$ 的第 $j$ 列换成 $b$ 得到的行列式。

> **局限性**：计算量大（需要算 $n+1$ 个 $n$ 阶行列式），实际很少用于数值计算。但其理论价值在于给出了显式解。
