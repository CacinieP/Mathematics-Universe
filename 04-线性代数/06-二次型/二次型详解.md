# 二次型详解

## 一、二次型的矩阵表示

$f(x_1,x_2,\ldots,x_n) = \mathbf{x}^TA\mathbf{x}$

**要求**：$A$ 是实对称矩阵（$A = A^T$）

**案例**：$f = x_1^2+4x_1x_2+2x_2^2$

$A = \begin{pmatrix}1&2\\2&2\end{pmatrix}$

验证：$(x_1,x_2)\begin{pmatrix}1&2\\2&2\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix} = x_1^2+2x_1x_2+2x_2x_1+2x_2^2 = x_1^2+4x_1x_2+2x_2^2$ ✓

## 二、标准化方法

### 2.1 正交变换法

**步骤**：
1. 写出 $A$ 的特征方程
2. 求特征值 $\lambda_1,\ldots,\lambda_n$ 和特征向量
3. 将特征向量正交化、单位化
4. 排成正交矩阵 $Q$
5. 令 $\mathbf{x} = Q\mathbf{y}$，则 $f = \lambda_1 y_1^2+\cdots+\lambda_n y_n^2$

### 2.2 配方法

**步骤**：
1. 若含 $x_i^2$ 项，对 $x_i$ 配方
2. 若不含 $x_i^2$ 但含 $x_ix_j$，先做变换产生平方项
3. 重复直到消去所有交叉项

**案例**：$f = x_1^2+2x_1x_2+2x_2^2-6x_2x_3$

配方：$f = (x_1+x_2)^2+x_2^2-6x_2x_3$

$= (x_1+x_2)^2+(x_2-3x_3)^2-9x_3^2$

令 $y_1=x_1+x_2$，$y_2=x_2-3x_3$，$y_3=x_3$

$f = y_1^2+y_2^2-9y_3^2$

**规范形**：正、负平方项的个数分别称为正、负惯性指数；正惯性指数 + 负惯性指数 = 秩（"零的个数"即 $n-r$，不属于惯性指数）。本例中正惯性指数为 2，负惯性指数为 1，秩为 3。

## 三、正定性的应用

### 3.1 正定判别

| 方法 | 正定条件 |
|------|----------|
| 定义法 | $\forall\mathbf{x}\neq 0$，$\mathbf{x}^TA\mathbf{x}>0$ |
| 特征值 | 所有 $\lambda_i > 0$ |
| 顺序主子式 | $\Delta_1>0$，$\Delta_2>0$，$\cdots$，$\Delta_n>0$ |
| 合同标准形 | 正惯性指数 = $n$ |

### 3.2 正定矩阵的性质

1. 正定矩阵的逆矩阵也是正定的
2. 两个正定矩阵之和是正定的
3. 正定矩阵的行列式 > 0
4. 正定矩阵的对角元素 > 0

### 3.3 与多元极值的联系

$f(\mathbf{x})$ 在驻点 $\mathbf{x}_0$ 处：
- $H(\mathbf{x}_0)$ 正定 ⟹ 极小值
- $H(\mathbf{x}_0)$ 负定 ⟹ 极大值
- $H(\mathbf{x}_0)$ 不定 ⟹ 鞍点

**案例**：$f(x,y) = x^3+y^3-3xy$

$\frac{\partial f}{\partial x} = 3x^2-3y = 0$，$\frac{\partial f}{\partial y} = 3y^2-3x = 0$

驻点：$(0,0)$ 和 $(1,1)$

在 $(1,1)$ 处：$H = \begin{pmatrix}6&-3\\-3&6\end{pmatrix}$

$\Delta_1 = 6 > 0$，$\Delta_2 = 36-9 = 27 > 0$

$H$ 正定，$(1,1)$ 是极小值点。

在 $(0,0)$ 处：$H = \begin{pmatrix}0&-3\\-3&0\end{pmatrix}$，$|H| = -9 < 0$，不定，鞍点。
