# 矩阵详解

## 一、矩阵运算

### 1.1 矩阵乘法的性质

- $(AB)C = A(BC)$（结合律）
- $A(B+C) = AB+AC$（左分配律）
- $(B+C)A = BA+CA$（右分配律）
- $(AB)^T = B^TA^T$
- $(AB)^{-1} = B^{-1}A^{-1}$

**不满足**：
- $AB \neq BA$（交换律不成立）
- $AB = 0$ 不能推出 $A=0$ 或 $B=0$

### 1.2 逆矩阵

**求法**：
1. 伴随矩阵法：$A^{-1} = \frac{A^*}{|A|}$
2. 初等行变换：$(A|I) \to (I|A^{-1})$
3. 分块矩阵法（大矩阵）

**性质**：
- $(A^{-1})^{-1} = A$
- $(kA)^{-1} = \frac{1}{k}A^{-1}$
- $(A^T)^{-1} = (A^{-1})^T$
- $|A^{-1}| = |A|^{-1}$

### 1.3 矩阵方程求解

**类型一**：$AX = B$（$A$ 可逆）⟹ $X = A^{-1}B$

**类型二**：$XA = B$ ⟹ $X = BA^{-1}$

**类型三**：$AXB = C$ ⟹ $X = A^{-1}CB^{-1}$

## 二、矩阵的秩

### 2.1 秩的重要等式

$$r(A) + r(B) - n \leq r(AB) \leq \min(r(A), r(B))$$

其中左端不等式即 **Sylvester不等式**。

**特殊情形**：
- $A$ 列满秩（$r(A)=n$）⟹ $r(AB) = r(B)$
- $B$ 行满秩（$r(B)=n$）⟹ $r(AB) = r(A)$
- $AB = 0$ ⟹ $r(A)+r(B) \leq n$

### 2.2 伴随矩阵的秩

设 $A$ 是 $n$ 阶矩阵（$n \geq 2$）：

| $r(A)$ | $r(A^*)$ |
|---------|-----------|
| $n$ | $n$ |
| $n-1$ | $1$ |
| $< n-1$ | $0$ |

## 三、分块矩阵

### 3.1 分块对角矩阵

$\begin{pmatrix}A&0\\0&B\end{pmatrix}^{-1} = \begin{pmatrix}A^{-1}&0\\0&B^{-1}\end{pmatrix}$

$\left|\begin{pmatrix}A&0\\0&B\end{pmatrix}\right| = |A||B|$

### 3.2 常用分块

$\begin{pmatrix}A&B\\0&D\end{pmatrix}^{-1} = \begin{pmatrix}A^{-1}&-A^{-1}BD^{-1}\\0&D^{-1}\end{pmatrix}$
