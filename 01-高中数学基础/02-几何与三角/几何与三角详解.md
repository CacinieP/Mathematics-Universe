# 几何与三角详解

## 一、三角函数深化

### 1.1 三角恒等式体系

**基础恒等式**：
- $\sin^2\alpha + \cos^2\alpha = 1$
- $1 + \tan^2\alpha = \sec^2\alpha$
- $1 + \cot^2\alpha = \csc^2\alpha$

**和角/差角**：
$$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$
$$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$
$$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$$

**倍角**（令 $\beta = \alpha$）：
$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$
$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

**半角**（由倍角反推）：
$$\sin^2\frac{\alpha}{2} = \frac{1-\cos\alpha}{2}, \quad \cos^2\frac{\alpha}{2} = \frac{1+\cos\alpha}{2}$$

**和差化积**：
$$\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$$
$$\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$$

**积化和差**：
$$\sin A\cos B = \frac{1}{2}[\sin(A+B)+\sin(A-B)]$$

> **与Fourier分析的联系**：积化和差公式本质上是三角函数的"乘积分解"——两个频率的乘积产生和频与差频。这就是无线电中"混频"的数学原理。

### 1.2 解三角形

**正弦定理**：
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

其中 $R$ 是外接圆半径。

**余弦定理**：
$$c^2 = a^2 + b^2 - 2ab\cos C$$

> **与线性代数的联系**：余弦定理就是向量内积的几何表达。$\mathbf{c} = \mathbf{a} - \mathbf{b}$，$|\mathbf{c}|^2 = |\mathbf{a}|^2 + |\mathbf{b}|^2 - 2\mathbf{a}\cdot\mathbf{b}$，其中 $\mathbf{a}\cdot\mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos C$。

**面积公式**：
$$S = \frac{1}{2}ab\sin C = \frac{1}{2}ah = \sqrt{s(s-a)(s-b)(s-c)}$$

其中 $s = \frac{a+b+c}{2}$（Heron公式）。

## 二、平面几何核心

### 2.1 圆

**重要定理**：
- 圆周角 = 同弧圆心角的一半
- 直径所对圆周角 = 90°
- 切线 ⟂ 半径
- 切割线定理、相交弦定理

**圆的方程**：
- 标准：$(x-a)^2 + (y-b)^2 = r^2$
- 一般：$x^2+y^2+Dx+Ey+F=0$（$D^2+E^2-4F > 0$）

### 2.2 圆锥曲线

**焦点—准线统一定义**：到定点（焦点）距离与到定直线（准线）距离之比为常数 $e$（离心率）。

| 曲线 | $e$ | 标准方程 | 焦点 |
|------|-----|----------|------|
| 椭圆 | $0 < e < 1$ | $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ | $(\pm c, 0)$，$c^2=a^2-b^2$ |
| 抛物线 | $e = 1$ | $y^2 = 2px$ | $(\frac{p}{2}, 0)$ |
| 双曲线 | $e > 1$ | $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$ | $(\pm c, 0)$，$c^2=a^2+b^2$ |

**椭圆的重要性质**：
- $a^2 = b^2 + c^2$（$a$半长轴，$b$半短轴，$c$半焦距）
- 椭圆上任意一点到两焦点的距离之和 = $2a$（定义）
- 面积 = $\pi ab$

**双曲线的渐近线**：$y = \pm\frac{b}{a}x$

> **与物理的联系**：
> - 行星轨道是椭圆（Kepler第一定律）
> - 抛体运动的轨迹是抛物线（Galileo）
> - 双曲线用于航天中的引力弹弓轨道

> **与高数的联系**：圆锥曲线是二次曲面（椭球面、抛物面、双曲面）的二维特例。二次部分的惯性、秩，以及一次项和常数项共同决定曲线类型。例如 $x^2+y^2=1$ 是圆，$x^2+y^2=-1$ 无实点；不能仅凭正定或负定判断实椭圆与虚椭圆。

## 三、立体几何

### 3.1 空间关系

**线线关系**：平行、相交、异面
**线面关系**：直线在平面内、平行、相交（斜交/垂直）
**面面关系**：重合、平行、相交

### 3.2 空间向量方法

**法向量**：平面 $\pi$ 的法向量 $\mathbf{n}$ 垂直于平面内所有向量。

**点到平面距离**：$d = \frac{|\mathbf{n}\cdot\overrightarrow{PQ}|}{|\mathbf{n}|}$

**二面角**：两个平面法向量的夹角（或其补角）。

**线面角**：取直线方向向量与平面法向量所成的最小夹角 $\theta\in[0,\pi/2]$，线面角为 $\pi/2-\theta$。

> **与线性代数的联系**：
> - 对 $A\mathbf{x} = d$：平面的方向空间 = null($A$)（即 $A$ 的行空间的正交补）；其基可选为两个独立的面内方向向量；平面的法向量 = $A$ 的行向量本身（属行空间，不在零空间）
> - 点到平面距离 = 投影到法向量方向的分量

### 3.3 空间几何体

| 几何体 | 体积 | 表面积 |
|--------|------|--------|
| 球 | $\frac{4}{3}\pi r^3$ | $4\pi r^2$ |
| 圆柱 | $\pi r^2 h$ | $2\pi r(r+h)$ |
| 圆锥 | $\frac{1}{3}\pi r^2 h$ | $\pi r(r+l)$，$l=\sqrt{r^2+h^2}$ |
| 棱锥 | $\frac{1}{3}Sh$ | — |

**球的体积推导**（积分直觉）：

考虑半径为 $r$ 的球。在高度 $z$ 处的截面是圆，半径为 $\sqrt{r^2-z^2}$，面积为 $\pi(r^2-z^2)$。

$$V = \int_{-r}^{r}\pi(r^2-z^2)dz = \pi\left[r^2 z - \frac{z^3}{3}\right]_{-r}^{r} = \pi\left(2r^3 - \frac{2r^3}{3}\right) = \frac{4}{3}\pi r^3$$

> 这是高中用祖暅原理（Cavalieri原理）的严格版本——用定积分代替直觉。

## 四、解析几何——代数与几何的桥梁

### 4.1 直线

**方向向量**：$\mathbf{d} = (l, m, n)$

**参数方程**：$(x,y,z) = (x_0,y_0,z_0) + t(l,m,n)$

**两直线关系**：
- 平行：方向向量平行
- 相交：解方程组有解
- 异面：方向向量与连线向量的三重积 $\neq 0$

**异面直线距离**：$d = \frac{|(\mathbf{d_1}\times\mathbf{d_2})\cdot\overrightarrow{P_1P_2}|}{|\mathbf{d_1}\times\mathbf{d_2}|}$

### 4.2 空间曲面

**球面**：$(x-a)^2+(y-b)^2+(z-c)^2 = r^2$

**椭球面**：$\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2} = 1$

**单叶双曲面**：$\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2} = 1$（直纹面！可以用直线织出）

**双叶双曲面**：$\frac{x^2}{a^2}-\frac{y^2}{b^2}-\frac{z^2}{c^2} = 1$

**椭圆抛物面**：$z = \frac{x^2}{a^2}+\frac{y^2}{b^2}$

**双曲抛物面（马鞍面）**：$z = \frac{x^2}{a^2}-\frac{y^2}{b^2}$

> **与高等数学的联系**：多元函数的等高面（$f(x,y,z) = c$）就是曲面。在梯度非零的正则点，梯度方向是等高面的法向量方向。
