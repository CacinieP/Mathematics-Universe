# 函数与代数详解

## 一、集合——数学的共同语言

### 1.1 集合的运算

- 并：$A \cup B = \{x | x \in A \text{ 或 } x \in B\}$
- 交：$A \cap B = \{x | x \in A \text{ 且 } x \in B\}$
- 补：$\bar{A} = \{x | x \in U, x \notin A\}$
- 差：$A \setminus B = \{x | x \in A, x \notin B\}$

**De Morgan律**：
$$\overline{A \cup B} = \bar{A} \cap \bar{B}, \quad \overline{A \cap B} = \bar{A} \cup \bar{B}$$

> **与概率论的联系**：De Morgan律在概率论中用于 $P(\overline{A \cup B}) = P(\bar{A}\cap\bar{B})$，是"至少发生一个"的逆事件="都不发生"。

### 1.2 映射

**映射三要素**：定义域 $A$、陪域（目标集合）$B$、对应法则。值域 $f(A)$ 是 $B$ 的子集；满射要求 $f(A)=B$。

| 类型 | 条件 | 例子 |
|------|------|------|
| 单射 | $f(a) = f(b) \Rightarrow a = b$ | $f(x) = 2x$ |
| 满射 | $\forall y \in B, \exists x, f(x) = y$ | $f(x) = x^3$（$\mathbb{R}\to\mathbb{R}$） |
| 双射 | 单射且满射 | $f(x) = x$ |

> **与线性代数的联系**：线性映射的单射性等价于核为零（$Ker(T) = \{0\}$），满射性等价于像是整个目标空间。有限维空间上，单射⟺满射⟺双射（要求 $\dim V = \dim W$，如 $V \to V$ 自身映射；不等维时不成立，如 $\mathbb{R}^2 \to \mathbb{R}^3$ 单射非满射）。

## 二、函数的深入分析

### 2.1 函数的复合与反函数

**复合**：$(f \circ g)(x) = f(g(x))$

链式法则：$(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$

**反函数存在条件**：$f$ 严格单调⟹反函数存在且也严格单调。

反函数求导：若 $f$ 在区间上连续、严格单调，在 $x$ 处可导且 $f'(x)\neq0$，则 $(f^{-1})'(y) = \frac{1}{f'(x)}$，其中 $y = f(x)$。

**案例**：$f(x) = e^x$ 的反函数是 $g(y) = \ln y$。
$$(\ln y)' = \frac{1}{(e^x)'} = \frac{1}{e^x} = \frac{1}{y}$$

### 2.2 函数性质的系统研究

**单调性判定**：

| 方法 | 适用 | 操作 |
|------|------|------|
| 定义法 | 任何函数 | 取 $x_1<x_2$，比较 $f(x_1)$ 与 $f(x_2)$ |
| 导数法 | 可导函数 | $f'(x)>0$⟹增，$f'(x)<0$⟹减 |

**经典例题**：判断 $f(x) = x + \frac{1}{x}$ 的单调性。

$f'(x) = 1 - \frac{1}{x^2} = \frac{x^2-1}{x^2}$

- $x \in (1, +\infty)$ 或 $(-\infty, -1)$：$f'(x) > 0$，单调增
- $x \in (-1, 0)$ 或 $(0, 1)$：$f'(x) < 0$，单调减

**对称性**（定义域须关于原点对称）：
- $f(x) + f(-x) = 0$⟹奇函数（关于原点对称）
- $f(x) - f(-x) = 0$⟹偶函数（关于 $y$ 轴对称）

**应用**：$\int_{-a}^{a}f(x)dx = \begin{cases}0, & \text{奇函数}\\2\int_0^a f(x)dx, & \text{偶函数}\end{cases}$

**周期性**：
- $\sin x, \cos x$：周期 $2\pi$
- $\tan x, \cot x$：周期 $\pi$
- 若 $f$ 周期为 $T$，则 $\int_a^{a+T}f(x)dx$ 与 $a$ 无关

### 2.3 基本初等函数深入

**指数函数 $y = a^x$**：

核心性质：
- $a^x \cdot a^y = a^{x+y}$（加法→乘法的桥梁）
- $(a^x)' = a^x \ln a$（特殊的 $a=e$ 时，$(e^x)' = e^x$）
- 当 $a > 1$：单调增，$\lim_{x\to-\infty}a^x = 0$，$\lim_{x\to+\infty}a^x = +\infty$
- 当 $0 < a < 1$：单调减

> **工程联系**：指数增长/衰减模型。$N(t) = N_0 e^{kt}$，$k>0$为增长，$k<0$为衰减（放射性衰变）。

**对数函数 $y = \log_a x$**（$a>0$、$a\neq1$、$x>0$）：

核心性质：
- $\log_a(xy) = \log_a x + \log_a y$（乘法→加法）
- $\log_a x^p = p\log_a x$
- 换底公式：$\log_a b = \frac{\ln b}{\ln a}$
- $(\ln x)' = \frac{1}{x}$（最简洁的导数之一）

**案例**：证明 $\ln x < x - 1$ 对 $x > 0, x \neq 1$。

令 $f(x) = x - 1 - \ln x$，$f(1) = 0$

$f'(x) = 1 - \frac{1}{x}$
- $x > 1$：$f'(x) > 0$，$f(x) > f(1) = 0$
- $0 < x < 1$：$f'(x) < 0$，$f(x) > f(1) = 0$

所以 $\ln x < x - 1$ 对所有 $x > 0, x \neq 1$ 成立。

> **与信息论的联系**：$\ln x \leq x - 1$ 可用于证明 KL散度非负 $D(P\|Q) \geq 0$。

**幂函数 $y = x^\alpha$**：

- $\alpha$ 为正整数：多项式
- $\alpha = \frac{p}{q}$（既约分数）：根式函数
- $\alpha = -1$：反比例函数（$\alpha = -2$ 时为 $\frac{1}{x^2}$ 等）
- $\alpha$ 为无理数：$x^\alpha = e^{\alpha \ln x}$

**三角函数**：

| 函数 | 定义域 | 值域 | 周期 | 奇偶 |
|------|--------|------|------|------|
| $\sin x$ | $\mathbb{R}$ | $[-1,1]$ | $2\pi$ | 奇 |
| $\cos x$ | $\mathbb{R}$ | $[-1,1]$ | $2\pi$ | 偶 |
| $\tan x$ | $x\neq\frac{\pi}{2}+k\pi$ | $\mathbb{R}$ | $\pi$ | 奇 |

**核心公式**：
- $\sin^2 x + \cos^2 x = 1$
- $\sin(x \pm y) = \sin x\cos y \pm \cos x\sin y$
- $\cos(x \pm y) = \cos x\cos y \mp \sin x\sin y$
- 和差化积、积化和差（由上述公式推导）

## 三、不等式

### 3.1 基本不等式

**均值不等式链**（$a,b>0$）：
$$\frac{2}{\frac{1}{a}+\frac{1}{b}} \leq \sqrt{ab} \leq \frac{a+b}{2} \leq \sqrt{\frac{a^2+b^2}{2}}$$

调和均值 ≤ 几何均值 ≤ 算术均值 ≤ 平方均值

等号成立 ⟺ $a = b$

> **与高数的联系**：Jensen不等式是均值不等式的一般化——凸函数在均值处的值 ≤ 均值的函数值。

### 3.2 Cauchy-Schwarz不等式

$$(a_1b_1+a_2b_2+\cdots+a_nb_n)^2 \leq (a_1^2+\cdots+a_n^2)(b_1^2+\cdots+b_n^2)$$

**向量形式**：$(\mathbf{a}\cdot\mathbf{b})^2 \leq |\mathbf{a}|^2|\mathbf{b}|^2$

**积分形式**：$\left(\int fg\right)^2 \leq \int f^2 \cdot \int g^2$

> **统一性**：高中代数、线性代数（内积）、实分析（$L^2$空间）共用同一个不等式。

### 3.3 绝对值不等式

$$|a| - |b| \leq |a \pm b| \leq |a| + |b|$$

> **与ε-δ语言的联系**：$|f(x) - L| < \varepsilon$ 的放缩就是用三角不等式。

## 四、数列

### 4.1 等差数列

通项：$a_n = a_1 + (n-1)d$

求和：$S_n = \frac{n(a_1+a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$

**性质**：$a_1 + a_n = a_2 + a_{n-1} = \cdots$

### 4.2 等比数列

通项：$a_n = a_1 q^{n-1}$

求和（$q \neq 1$）：$S_n = \frac{a_1(1-q^n)}{1-q}$

**注意**：当 $|q| < 1$ 时，$\lim_{n\to\infty}S_n = \frac{a_1}{1-q}$（无穷等比级数求和公式）

> **与级数的联系**：这就是 $\sum_{n=0}^{\infty}q^n = \frac{1}{1-q}$（$|q|<1$），Taylor级数的特例。

### 4.3 求和方法

**裂项相消**：
$$\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1} \Rightarrow \sum_{k=1}^n\frac{1}{k(k+1)} = 1 - \frac{1}{n+1}$$

**错位相减**：适用于 $a_n = b_n \cdot c_n$，其中 $\{b_n\}$ 等差，$\{c_n\}$ 等比。

**倒序相加**：$\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$（公式用归纳法/递推导出；倒序相加适用于等差数列）

**数学归纳法**：
1. 验证 $n=1$ 成立
2. 假设 $n=k$ 成立，证明 $n=k+1$ 也成立
3. 结论：对所有 $n \geq 1$ 成立

### 4.4 案例：用归纳法证明 Bernoulli不等式

$(1+x)^n \geq 1 + nx$ 对 $x > -1, n \in \mathbb{N}$。

**证明**：
- $n=1$：$(1+x)^1 = 1 + x$ ✓
- 设 $n=k$ 成立：$(1+x)^k \geq 1+kx$
- $n=k+1$：$(1+x)^{k+1} = (1+x)^k(1+x) \geq (1+kx)(1+x) = 1+(k+1)x+kx^2 \geq 1+(k+1)x$ ✓

> **与高数的联系**：Bernoulli不等式是证明数列 $(1+1/n)^n$ 单调增的关键工具。
