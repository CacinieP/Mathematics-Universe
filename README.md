# 数学知识体系：环环相扣的联系网络

> 数学不是孤立定理的堆砌，而是一棵从几条根出发、不断分叉又不断融合的生命之树。

## 设计哲学

本仓库遵循三个核心原则：

1. **环环相扣**：每个概念都标注它的"上游"（它依赖什么）和"下游"（它通向什么），形成有向无环图
2. **历史脉络**：数学思想不是凭空产生的，每个重大概念的诞生都有其历史动因
3. **思维模型**：提炼出可迁移的结构化思维方法，而非单纯的知识点罗列

## 难度标注系统

每个文件使用难度标记：

- `[基础]` 高中水平，理解概念即可
- `[标准]` 大学本科必修，考研数学一/二/三要求
- `[进阶]` 考研难题、数学专业基础课水平
- `[拓展]` 超出考研范围，但有助于深化理解

## 联系标注系统

每个概念文件末尾包含联系框：

```
━━━ 联系网络 ━━━
⬆ 上游: [依赖的概念]
⬇ 下游: [通向的概念]
↔ 横联: [并列或类比的概念]
🔗 跨域: [其他分支的联系]
━━━━━━━━━━━━━━
```

## 如何使用本仓库

- **考研备考**：重点关注 03-05 + 09 目录，按"总览→概念→例题→联系"顺序学习
- **体系构建**：从 00 开始，沿知识图谱走完全程，注意 02（衔接）和 08（联系网络）
- **兴趣探索**：07（数学史）提供了每个概念的"故事"，适合碎片阅读
- **工科应用**：每个概念文件末尾有"工程视角"一节，说明该概念在工程中的实际用途
- **冲刺提分**：10-十天攻坚计划提供了140+的系统化冲刺方案，含高频失分点清单
